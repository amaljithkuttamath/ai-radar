### Main list

#### Video
**SolarWM: Open Data and Scalable Training for Long-Horizon Video World Models** · 4/5  
[arXiv](https://arxiv.org/abs/2609.02886) · [code](https://github.com/Junchao-cs/SolarWM) · [project](https://junchao-cs.github.io/SolarWM-Web/)  
Eight runs in, traction still accelerating (582★, 150 HF ↑, +343% since Sept 3). The first fully open pipeline — heterogeneous data prep, multiple video backbones, long-horizon inference — that lets anyone train interactive world models. Frontier-group authorship (Junchao Chen et al.) and a live demo make this the reference stack for video world model research.

**DreamLayer-Eval: Open-Source Benchmarking for Image & Video Diffusion** · 4/5  
[GitHub](https://github.com/TheDesignFounder/DreamLayer-Eval) (411★)  
Automates prompts, seeds, and metrics for reproducible diffusion evaluation. From DreamLayer AI. Second run, traction flat — useful infrastructure, but not yet a community standard.

#### Benchmark
**EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction** · 4/5  
[arXiv](https://arxiv.org/abs/2609.02783) · [code](https://github.com/inphotoo/earlyeval) (6★, 120 HF ↑)  
Cuts agent benchmark cost by predicting final outcomes from partial trajectories — 10–50× cheaper per eval run. Eight runs, traction rising (+112%). Matches FOCUS (agents/evaluation). The artifact is usable; the benchmark-distillation approach is the practical lever teams need today.

**GAIA Benchmark (HF Dataset)** · 4/5  
[Hugging Face](https://huggingface.co/datasets/gaia-benchmark/GAIA)  
The standard general-assistant benchmark (multi-modal, tool-use, reasoning) — now trending on HF. Third run, traction flat. Matches FOCUS (benchmark). Essential reference; the dataset itself is the artifact.

#### Other
**microsoft/foldingdiff: Diffusion Models of Protein Structure** · 4/5  
[GitHub](https://github.com/microsoft/foldingdiff) (567★)  
Trigonometry + attention for protein backbone generation. Microsoft Research, third run, traction flat. Matches FOCUS (attention). Strong group, clean codebase — a reference implementation for diffusion on SO(3) manifolds.

**book-to-skill: Turn Any Technical PDF into a Claude Code Skill** · 3/5  
[GitHub](https://github.com/virgiliojr94/book-to-skill) (30,394★)  
Brand-new breakout: ingests a PDF, extracts concepts, emits a Claude Code skill you can query while coding. No research novelty, but 30k stars in days signals acute practitioner pain — “I want my library docs as a live coding assistant.” Watch for forks targeting other editors.

### Insights
- **Video world models are consolidating around open data + multi-backbone training.** SolarWM and DreamLayer-Eval (benchmarking) form a natural pair: one builds, the other measures.
- **Agent evaluation cost is the active bottleneck.** EarlyEval’s early-exit prediction and GAIA’s standardization attack the same problem from opposite ends — expect convergence.
- **“PDF → skill” utilities are the new “PDF → chat”.** book-to-skill’s 30k stars and Repo-To-Skill’s 8-run arc show developers want executable knowledge, not RAG chat.
- **Protein diffusion (foldingdiff) remains a quiet stronghold.** Microsoft’s repo holds steady at 567★ — specialized but high-quality; worth watching if diffusion hits structure prediction benchmarks.
