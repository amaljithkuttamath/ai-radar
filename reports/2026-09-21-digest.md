## Main list

### [LynnReal-Omni: Native multi-modal Video Generation for Agentic Visual Workflows](https://arxiv.org/abs/2609.15863) · 4/5
A video diffusion model built for agentic control — it accepts explicit 3D scene references, editable layouts, and executable game states as conditioning, trading pure generative freedom for the temporal coherence that long-horizon workflows demand. The GitHub repo (210 stars, 55 HF upvotes) ships inference code and weights, making this immediately testable for anyone building visual agents that need to *stay on target* across seconds of generated footage. Sixth radar appearance, traction still climbing ~3× since first seen. [code](https://github.com/LynnReal-AI/LynnReal-Omni) · [project](https://github.com/LynnReal-AI/LynnReal-Omni)

### [abenzerps/Qwen-Image-2.1-GGUF](https://huggingface.co/abenzerps/Qwen-Image-2.1-GGUF) · 3/5
GGUF-quantized weights for Qwen-Image 2.1, enabling CPU/Apple Silicon inference without a full GPU stack. The base model (from Qwen/Alibaba) is a strong open text-to-image foundation; this repackaging makes it practical for local-first workflows and ComfyUI pipelines. Trending on HF with strong Tier-2 traction signals.

### [Comfy-Org/Qwen-Image-2.1](https://huggingface.co/Comfy-Org/Qwen-Image-2.1) · 3/5
Official ComfyUI single-file distribution of Qwen-Image 2.1 (diffusion-single-file format). Drop-in for existing Comfy graphs — no custom nodes, no converter step. Same base model as above, packaged for the largest open visual-workflow ecosystem. HF trending, US license tag.
