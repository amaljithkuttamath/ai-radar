## Main list

### 1. intel/neural-compressor — SOTA low-bit LLM quantization · 4/5
[GitHub](https://github.com/intel/neural-compressor) · 2,712★  
Intel's production quantization stack now supports INT8, FP8, MXFP8, INT4, MXFP4, and NVFP4 across PyTorch, TensorFlow, and ONNX Runtime. The star velocity (2.7k in two days) reflects real deployment pain: teams need drop-in compression that preserves accuracy on diverse hardware. Weights-only and weight-activation quantization, sparsity pruning, and automatic calibration are all baked in. If you're shipping LLMs anywhere outside a GPU cluster, this is the first artifact to evaluate.

### 2. GameHorizon Suite: Multi-Horizon Data and Evaluation in Gameplay · 4/5
[arXiv](https://arxiv.org/abs/2609.25001) · [GitHub](https://github.com/TencentARC/GameHorizon) · [Project](https://gamehorizon-suite.github.io/) · 294★, 130 HF ↑  
*Continuing — 5th run, stars 285 → 294.* A unified benchmark suite spanning 20+ games with language instructions, replacing high-variance online rollouts with reproducible offline evaluation. Tencent's release includes datasets, environments, and baselines for visual understanding, planning, and control across temporal horizons. The star growth is steady; this is becoming the standard reference for game-playing agents.

### 3. LynnReal-Omni: Native multi-modal Video Generation for Agentic Visual Workflows · 4/5
[arXiv](https://arxiv.org/abs/2609.15863) · [GitHub](https://github.com/LynnReal-AI/LynnReal-Omni) · 230★, 56 HF ↑  
*Continuing — 11th run, stars 224 → 230.* Native multi-modal video generation conditioned on explicit 3D references, editable scenes, and executable game states — solving the drift and control problems of pure diffusion. The repo includes training code and checkpoints. Traction remains strong across nearly two weeks; the agentic-video-control niche is consolidating here.

### 4. vectorize-io/hindsight — Hindsight: Agent Memory That Learns · 3/5
[GitHub](https://github.com/vectorize-io/hindsight) · 35,919★  
An agent memory layer that extracts, consolidates, and retrieves lessons from past executions — turning ephemeral context into persistent, queryable knowledge. The extraordinary star count (36k) suggests this hit a nerve: everyone building agents is fighting the memory bottleneck. Early release; API stability and evals are the watch items.

### 5. ianarawjo/ChainForge — Visual programming environment for battle-testing prompts · 3/5
[GitHub](https://github.com/ianarawjo/ChainForge) · 3,030★  
Node-based UI for composing, versioning, and regression-testing prompt chains across models. Fills the gap between notebook tinkering and CI/CD for prompts. TypeScript/React stack, self-hostable. 3k stars in days indicates strong practitioner pull.

### 6. Viggle/Qwen-Image-2.1-viggle-turbo · 3/5
[Hugging Face](https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo)  
Viggle's turbo-distilled Qwen-Image 2.1 variant — faster inference, LoRA-ready, supports text-to-image, image-to-image, and editing. Weights on HF, diffusers-compatible. No public benchmarks yet; treat as a capable base for fine-tuning rather than a standalone SOTA claim.

### 7. BreCaspian/Deep_Learning_Foundation_and_Concepts-Springer · 3/5
[GitHub](https://github.com/BreCaspian/Deep_Learning_Foundation_and_Concepts-Springer) · 111★  
Complete open-source release of the Springer textbook *Deep Learning: Foundations and Concepts* — LaTeX source, figures, Jupyter notebooks, and slides. Rare case of a major publisher green-lighting full open access. Solid reference for onboarding or curriculum design.

## Insights

- **Quantization tooling has crossed the adoption chasm.** Intel's 2.7k stars in 48h isn't hype — it's teams grabbing a solution for the "last mile" of LLM deployment on CPUs and edge accelerators. Expect MXFP4/NVFP4 kernels to become standard in inference stacks by Q1 2027.
- **Agent infrastructure is fragmenting into specialized layers.** Memory (Hindsight), prompt engineering (ChainForge), evaluation (GameHorizon), and video control (LynnReal-Omni) are each getting dedicated OSS projects. The stack is verticalizing fast.
- **Open educational resources from major publishers are arriving.** The Springer textbook release follows a trend: publishers trading gatekeeping for mindshare as AI courseware demand explodes.
- **Game environments are the new unit test for generalist agents.** GameHorizon's multi-horizon, multi-game benchmark design — language instructions + offline eval — is the template future benchmarks will copy.
