## Main list

### 1. HarnessEval-W: Agentifying the Evaluation of Visual Worlds · 4/5
[Paper](https://arxiv.org/abs/2608.16859) · [Code](https://github.com/MirroS-Lab/HarnessEval-W) · [Project](https://mirros-lab.github.io/HarnessEval-W)  
**Continuing story (5th run, traction +3.1× since Aug 18).** A benchmark that replaces scalar scores with an LLM judge capable of spotting physics, causality, and state-consistency violations in world-model rollouts. 245 GitHub stars, 123 HF upvotes. If you build or evaluate video world models, this is the eval harness you've been missing — it automates the "human eye test" that until now only people could do.

### 2. Embodied-Navigator: Point, Think, Memorize, and Align for Efficient Navigation · 4/5
[Paper](https://arxiv.org/abs/2608.17512) · [Code](https://github.com/ZJU-OmniAI/Embodied-Omni) · [Project](https://zju-omniai.github.io/Embodied-Navigator/)  
**Continuing story (4th run, traction +3.0× since Aug 19).** TAMP-Nav framework aligns VLMs' 2D pre-training priors with 3D navigation via a unified point-think-memorize-act loop. 218 GitHub stars, 49 HF upvotes. Strong-group authorship (ZJU OmniAI). The memory module and action-space alignment are the transferable bits — relevant for any embodied agent stack.

### 3. huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF · 3/5
[GGUF model](https://huggingface.co/huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF) · [Base model](https://huggingface.co/huihui-ai/Huihui-Qwen3.8-27B-abliterated)  
Abliterated (refusal-removed) Qwen3 27B in GGUF, trending on HF. Image-text-to-text capability. Useful if you need an uncensored 27B multimodal model that runs locally; the abliteration approach preserves capabilities better than fine-tuning-based uncensoring.

### 4. 0bserverx/Qwen3.8-27B-Heretic-Abliterated-Uncensored-GGUF · 3/5
[Model](https://huggingface.co/0bserverx/Qwen3.8-27B-Heretic-Abliterated-Uncensored-GGUF)  
Independent abliterated Qwen3.8 27B GGUF release (Heretic variant). Text-generation only. Same utility profile as above — pick based on quantization preference and downstream evals.

### 5. nvidia/Cosmos3-DROID · 2/5
[Dataset](https://huggingface.co/datasets/nvidia/Cosmos3-DROID)  
NVIDIA's DROID robotics dataset (video, 1K–10K samples, open-mdw license). Part of the Cosmos 3 world-model push. If you train robotics world models or need real-world manipulation trajectories, this is a clean, licensed addition to your data mix.

## Insights

- **Abliteration wave**: Three independent abliterated Qwen3 27B GGUFs dropped in 48h — the technique (orthogonal refusal-direction removal) is commoditizing fast. Expect more sizes and base models.
- **Eval infrastructure hardening**: HarnessEval-W's judge-based approach and Evo-Bench's meta-benchmarking both signal a shift from "report a number" to "verify the reasoning." This is where the field's rigor gap is actually closing.
- **Robotics data going open-license**: NVIDIA's DROID under open-mdw-1.1 continues the trend of major labs releasing manipulation datasets with commercial-friendly terms — a quiet enabler for world-model training.
