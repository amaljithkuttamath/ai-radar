## Main list

### [OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video Interaction](https://arxiv.org/abs/2610.01762) · [code](https://github.com/MCG-NJU/OneStreamer) · [project](https://mcg-nju.github.io/OneStreamer) · 4/5
A streaming video LLM that builds query-independent factual memory while perceiving, then responds proactively when evidence is sufficient. The Proactive Head learns to trigger responses without an external prompt. 163 HF upvotes and 106 GitHub stars in two days — traction accelerated 2.5× since first seen. Relevant for anyone building long-context video agents or real-time monitoring.

### [utensils/mold — CLI-native local AI image and video generation](https://github.com/utensils/mold) · 3/5
Single binary (Rust) that runs diffusion models locally on CUDA (Linux) or Metal (macOS), with desktop, web, iPhone, REST/SSE, and MCP interfaces. 51 stars on day one. Targets scripts and agents, not just humans — the MCP server lets LLMs call image/video generation as a tool. Practical pick for local-first agent workflows.

### [Aleph-Alpha/Kolibri-1](https://huggingface.co/Aleph-Alpha/Kolibri-1) · 2/5
New MoE model from Aleph Alpha, tagged for vLLM and reasoning. Trending on Hugging Face; no public benchmarks or code yet. Watch for evals before adopting.

### [Yzmblog/DMAD — Distribution Matching as Adversarial Distillation for Fast Visual Generation](https://github.com/Yzmblog/DMAD) · 2/5
Adversarial distillation method that matches distributions for few-step generation. 73 stars, code available. Early-stage; compare against LCM/LCM-LoRA and SD-Turbo on your task before committing.

### [Venastine-Research/Xing4.0-29B-A4B-GGUF](https://huggingface.co/Venastine-Research/Xing4.0-29B-A4B-GGUF) · 2/5
29B MoE (4B active) in GGUF format. Trending on HF; conversational tag. No published benchmarks or training details — treat as experimental.

## Insights
- **Streaming video is converging on proactive memory.** OneStreamer, EVO-WAM, APM-Bench, and Beyond Memory all tackle the same problem: retain evidence before you know the query, then act when ready. The climb across all four suggests the community has settled on this as the next bottleneck.
- **CLI/tool-first interfaces are shipping faster than GUI agents.** mold (CLI-native, MCP-enabled) and HybridCUA (GUI+CLI orchestration) both appeared this window. The CLI path has a working artifact today; the GUI path is still benchmark-heavy.
- **MoE small models are flooding HF trending.** Kolibri-1 and Xing4.0-29B-A4B both hit trending without published evals. Signal is attention, not quality — wait for independent benchmarks.
