## Main list

### Evaluation

**Retrieve, Reproduce, Reveal: Dissecting Retrieval-Augmented Software Vulnerability Detection** [paper](http://arxiv.org/abs/2609.37669v1) · 3/5  
First open, reproducible study of six RAG-based vulnerability detectors across unified datasets and backbones. Finds retrieval quality matters more than generator size, and current RAG systems over-rely on synthetic vulnerabilities. Code and evaluation harness released.

**LoLBench: Evaluating Coding Agents with Long-Horizon Proposals on Large Software Systems** [paper](http://arxiv.org/abs/2609.37143v1) · 3/5  
Tests both *perception* (grounding intent to spec) and *implementation* (editing large repos) on real PR-derived tasks. Current agents solve ~35% of proposals; the gap is spec derivation, not coding. Repo and evaluation scripts open.

**OTROPE: Optimal Transport-based Robust Off-policy Evaluation for Large Language Models** [paper](http://arxiv.org/abs/2609.36264v1) · 3/5  
Likelihood-free off-policy evaluation using optimal transport to align behavior/target distributions. Works with black-box LLMs and scarce labels. Beats importance-sampling baselines on instruction-following and safety tasks. Implementation released.

**A Benchmark & Dataset for Detecting AI-Manipulated Visual Evidence in the Court System** [paper](http://arxiv.org/abs/2609.37783v1) · 3/5  
First forensics benchmark targeting *legal* imagery: surveillance, dashcam, phone photos altered via prompt-based tools. Covers 12 manipulation categories with provenance metadata. Dataset and detection baselines open.

**Benchmarking graph-based models for in-silico toxicity prediction in drug discovery** [paper](http://arxiv.org/abs/2609.37555v1) · 3/5  
Systematic comparison of 18 GNN architectures on 12 toxicity endpoints with scaffold splits. Finds message-passing depth and virtual nodes matter more than fancy attention; simple GraphSAGE + virtual node wins. Reproducible pipeline released.

**GNA: Granular Neighbor Assembly for Retrieval-Augmented Multivariate Time-Series Forecasting** [paper](http://arxiv.org/abs/2609.36281v1) · 3/5  
Retrieves per-variate neighbors at two granularities (whole-window + per-channel) instead of a single past window. Consistent gains on 8 real-world datasets; plug-and-play for any forecaster backbone. Code released.

### Long-context & Attention

**CoEM: Empowering Long-Context Reasoning with Commit-on-Evidence Memory** [paper](http://arxiv.org/abs/2609.36935v1) · 3/5  
Learns *when* to compress evidence into memory facts under a fixed budget, preserving critical details for multi-hop reasoning. Beats chunked baselines on 128k-context QA and multi-doc synthesis. Training code and checkpoints available.

**Cropland PAtteRNS: Parallel Dimensional Attention Networks for Crop Segmentation in Satellite Imagery Time Series** [paper](http://arxiv.org/abs/2609.38165v1) · 3/5  
First model applying separate self-attention per temporal, spectral, and spatial dimension of Sentinel-2 data. Sets new SOTA on 5 crop segmentation benchmarks; ablation shows each attention stream contributes. Weights and training scripts released.

### Releases

**orcarouter/OrcaSAQ-2-27B** [model](https://huggingface.co/orcarouter/OrcaSAQ-2-27B) · 3/5  
Qwen3.5-based 27B model optimized for structured output and agentic tool use via SAQ (Self-Ask Questioning) distillation. Trending on HF; safetensors + vLLM support. No paper yet — treat as capability probe.

**fastino/GLiNER2.5-Decide** [model](https://huggingface.co/fastino/GLiNER2.5-Decide) · 2/5  
Token-classification variant of GLiNER 2.5 tuned for intent classification, sentiment, and extraction. Small (encoder-scale), fast, Apache-2.0. Useful drop-in for structured NLP pipelines; no benchmark deltas published.

## Insights

- **Evaluation is eating research bandwidth.** Six rigorous benchmarks in one window — vulnerability detection, coding proposals, off-policy LLM eval, legal deepfakes, molecular toxicity, multivariate forecasting — signals a field moving from "my model beats yours" to "here's how we measure *any* model."  
- **Retrieval augmentation is fragmenting by modality.** GNA (per-variate time-series), CoEM (evidence-aware memory), OTROPE (distribution alignment) all retrieve, but each solves a different alignment problem. No unified retrieval layer yet.  
- **Agentic evaluation has split into perception vs. implementation.** LoLBench explicitly separates spec derivation from code editing; VideoGen-Agent (carryover) does the same for video tools. The pattern suggests future benchmarks will decompose agent capability along this axis.  
- **Carryovers are stabilizing, not exploding.** GameHorizon (+3%), VideoGen-Agent (+1%), neural-compressor (flat) — the early hype cycle has passed; these are now maintenance-mode projects with steady adoption.

## Action items

- **Read** Retrieve, Reproduce, Reveal + LoLBench together — they define the new standard for *reproducible agent evaluation* (RAG for sec, coding agents for dev).  
- **Try** CoEM if you're hitting context-window degradation on 128k+ tasks; the commit-on-evidence mechanism is a drop-in memory module.  
- **Track** OTROPE and GNA — both offer likelihood-free evaluation/retrieval that works with black-box APIs, a rare practical advantage.  
- **Benchmark** your coding agents on LoLBench's proposal split; the perception gap (spec derivation) is where current agents fail silently.  
- **Audit** your deepfake detection pipeline against the court-evidence dataset — existing forensics benchmarks don't cover prompt-based manipulation of legal imagery.
