## Main list

### Evaluation

**[GameHorizon Suite: Multi-Horizon Data and Evaluation in Gameplay](https://arxiv.org/abs/2609.25001) · [code](https://github.com/TencentARC/GameHorizon) · [project](https://gamehorizon-suite.github.io/) · 4/5**  
Continuing story (10th run). A TencentARC benchmark spanning 100+ games with language instructions, replacing high-variance online rollouts with reproducible offline evaluation. Traction up 3.4× since Sept 22 (466 stars, 131 HF upvotes). If you evaluate agents, this is the new standard.

**[Faynt: Scaling and Optimizing Policies for Competitive Melee](http://arxiv.org/abs/2610.02144v1) · 3/5**  
10M/75M Transformer policies controlling all 26 SSBM characters from one checkpoint. 98.4% win rate against specialist bots with zero action delay. Weights and training code released. A rare case of RL scaling to human-level play in a complex, real-time domain.

**[AVSD-Scenes: A Dataset for Audio-Visual Description of Urban Scenes](http://arxiv.org/abs/2610.01861v1) · 3/5**  
12K paired audio-visual descriptions generated via Qwen2-Audio-7B and Qwen2.5-VL-7B from TAU urban scenes. Modality-specific descriptions fused by an LLM. Dataset and generation pipeline released — useful for multimodal retrieval and captioning benchmarks.

**[TabJoinBench: A Benchmark for Joinable Table Discovery](http://arxiv.org/abs/2610.00817v1) · 3/5**  
First unified benchmark for join discovery across semantic, relational, and hybrid data-lake scenarios. Constructs query-candidate pairs from real sources with human-verified labels. Code and data released; fills a reproducibility gap in data-prep evaluation.

### Agents

**[EngiWorld: What Can Frontier Agents Deliver in Professional Engineering Environments?](https://arxiv.org/abs/2609.37686) · [code](https://github.com/Hongcheng-Gao/EngiWorld) · [project](https://engiworld.github.io/) · 4/5**  
Continuing story (3rd run). 1,301 expert-verified tasks across the full CAD/CAE/PLM design loop — geometric reasoning, physical constraints, cross-tool dependencies. Traction up 2.3× since Sept 30. The first benchmark that looks like actual engineering work, not toy coding tasks.

### Cost

**[Which LLM to pick? Online Active Model Selection for Large Language Models](http://arxiv.org/abs/2610.01592v1) · 3/5**  
ONLINE LLM PICKER: given a query stream and annotation budget, actively selects prompts to label and identifies the best model without full evaluation. Reduces annotation cost 60–80% vs. uniform sampling in experiments. Code released.

**[CODesign: Consistency from Data to Trajectory in All-Atom Protein Binder Co-Design](http://arxiv.org/abs/2610.01773v1) · 3/5**  
Joint sequence-structure generation with a consistency loss that couples the two modalities end-to-end. Improves binding affinity and design success rates over two-stage baselines. Weights and inference code released.

### Other

**[Tencent/WeKnora — Open-source LLM knowledge platform](https://github.com/Tencent/WeKnora) · 3/5**  
Exploded to 31.7k stars in days. Turns raw docs into a queryable RAG, an autonomous reasoning agent, and a self-maintaining wiki. Go backend, pluggable LLM providers, graph-based knowledge extraction. If you're building internal knowledge tools, this is the reference implementation to beat.

**[MWOP: Modality-aware Width-wise Operation Pruning for Efficient MLLMs](http://arxiv.org/abs/2610.01434v1) · 3/5**  
Finds redundancy varies *within* attention heads (across modality paths) and *within* FFN channels (visual vs. textual execution). Prunes at that granularity — 30% FLOPs reduction with <1% accuracy drop on LLaVA-v1.5-7B. Code released.

**[Cloudflare/clef-flash (HF Model)](https://huggingface.co/Cloudflare/clef-flash) · 3/5**  
Cloudflare's new vision-language model (Qwen3.5-based, image-text-to-text). Safetensors, Transformers-ready. Sister model `clef` (no `-flash`) is climbing in the HF trending list. No paper yet — treat as a capable VLM drop-in until benchmarks arrive.

## Insights

- **Evaluation infrastructure is maturing faster than agents.** GameHorizon, EngiWorld, TabJoinBench, Faynt, and AVSD-Scenes all ship reproducible offline benchmarks with released artifacts. The field is standardizing on "benchmark first, agent second."
- **Single-checkpoint generality is the new frontier.** Faynt (26 characters), GameHorizon (100+ games), and EngiWorld (full design loop) all emphasize one model handling diverse tasks without task-specific heads.
- **Open-source RAG platforms are consolidating.** WeKnora's 31k stars in days signals the market settling on "documents → graph RAG → agent → wiki" as a complete stack, not a pipeline you stitch yourself.
- **Width-wise pruning beats head-wise for MLLMs.** MWOP's finding — redundancy lives inside heads and channels, not across them — suggests the next compression gains come from finer-grained surgery.
