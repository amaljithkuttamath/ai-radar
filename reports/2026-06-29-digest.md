## Main list

### Dataset

- [Tencent-Hunyuan/HunyuanVideo — HunyuanVideo: A Systematic Framework For Large Video Generation Model](https://github.com/Tencent-Hunyuan/HunyuanVideo)  
  A comprehensive open framework for large-scale video generation, rapidly trending on GitHub with over **12,000 stars**. For teams working on generative video, it’s a production-grade artifact with significant real-world traction. · 3/5

- [CodeDevX/Vibe-Coding-Instruct (HF Dataset)](https://huggingface.co/datasets/CodeDevX/Vibe-Coding-Instruct)  
  New multi-million sample coding instruction dataset (Apache-2.0 license, JSON format) targeting text generation, trending on Hugging Face. Useful for those training or fine-tuning code synthesis models. · 3/5

- [deepreinforce-ai/Ornith-1.0-397B (HF Model)](https://huggingface.co/deepreinforce-ai/Ornith-1.0-397B)  
  Frontier group release: 397B parameter multilingual transformer model (includes conversational and image-text capabilities). Available through Hugging Face for immediate testing. · 3/5

### Agents

- [DMV-Bench: Diagnosing Long-Horizon Multimodal Agents' Visual Memory with Incidental Cue Injection](http://arxiv.org/abs/2606.27499v1)  
  Introduces a new benchmark focused on evaluating visual memory in multimodal agents over long time horizons—addressing weak spots in agent memory assessment. Usable artifact included. · 3/5

- [NormAct: A Benchmark for Hidden Social Norm Compliance in Embodied Planning](http://arxiv.org/abs/2606.27826v1)  
  Proposes a benchmark for evaluating how well multimodal embodied agents comply with implicit social norms in planning tasks—filling a key gap for socially-aware robotics and agentic systems. · 3/5

### Other

- [MultiHashFormer: Hash-based Generative Language Models](https://arxiv.org/abs/2606.28057) · [code](https://github.com/HUIYINXUE/MHF)  
  Advances token-efficient language modeling with hash-based embeddings, reducing parameter footprint while enabling encoder-decoder architectures. Trends with **15 HF upvotes**. · 3/5

- [Parallel Rollout Approximation for Pixel-Space Autoregressive Image Generation](https://arxiv.org/abs/2606.27978) · [code](https://github.com/MangataX/PRA)  
  Tackles the scaling bottlenecks in pixel-level AR image generation with parallel rollout approximations. Practical code artifact supplied—high value for generative image teams. · 3/5

- [Beyond Sparse Supervision: Diffusion-Guided Learning for Few-Shot Graph Fraud Detection](http://arxiv.org/abs/2606.28134v1)  
  Combines diffusion-guided learning with graph-based fraud detection under sparse supervision—a target problem for real-world financial anomaly systems. Usable artifact available. · 3/5

- [SpatialUAV: Benchmarking Spatial Intelligence for Low-Altitude UAV Perception, Collaboration, and Motion](http://arxiv.org/abs/2606.27876v1)  
  Provides a new benchmark and dataset for UAV spatial reasoning, collaboration, and navigation—addressing a real operational gap in aerial intelligence. · 3/5

- [FoggyTrust: Robust Federated Learning with Hierarchical Trust Networks](http://arxiv.org/abs/2606.27622v1)  
  Introduces a hierarchical trust mechanism for robust federated learning, focusing on resilience against malicious clients. Protocols and sample code are provided. · 3/5

- [Benchmarking Multi-Modal Graph-based Social Media Popularity Prediction](http://arxiv.org/abs/2606.27539v1)  
  Opens up a multi-modal graph benchmark for predicting social media content popularity, with implications for content recommendation and forecasting. · 3/5

- [Every Step of the Way: Video-based Parkinsonian Turning Step Counting](http://arxiv.org/abs/2606.27918v1)  
  Releases a new video-based method for counting Parkinsonian turning steps—concrete impact for healthcare analytics and monitoring. · 3/5

- [Aloe-Vision: Robust Vision-Language Models for Healthcare](http://arxiv.org/abs/2606.27500v1)  
  Presents a vision-language model specialized for clinical tasks, addressing the lack of robust, high-quality multimodal healthcare data. Results and code are available. · 3/5

- [Parameter Efficient Hybrid Transformer (PEHT) for Network Traffic Prediction via Dynamic Urban Congestion Integration](http://arxiv.org/abs/2606.28274v1)  
  Deploys a traffic prediction model using hybrid transformer architecture, integrating dynamic congestion effects—a step up for urban network optimization. · 3/5

## Insights

- Usable, open artifacts with benchmark datasets dominate attention and signal, more than generic model announcements.
- Video generation and agentic memory evaluation are rapidly advancing—multiple benchmarks released simultaneously.
- Robustness and social context benchmarks for agents are now critical, reflecting a shift toward real-world deployment concerns.
- Infrastructure releases (GPU latency datasets, federated learning protocols) remain high-utility but low-trending unless tied to major groups.
