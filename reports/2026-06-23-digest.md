## Main list

### Agents

**[PlanBench-XL: Evaluating Long-Horizon Planning of LLM Tool-Use Agents in Large-Scale Tool Ecosystems](https://arxiv.org/abs/2606.22388)** · [GitHub](https://github.com/JiayuJeff/PlanBench-XL) · [Project](https://planbench-xl.github.io/)  
A landmark benchmark addressing the real challenge of LLM agents: navigating vast tool environments, discovering relevant capabilities, and executing plans in dynamic conditions. With strong upvotes (71 HF) and released code, PlanBench-XL is likely to become the reference evaluation for agent planning.  
· 4/5

**[EnterpriseClawBench: Benchmarking Agents from Real Workplace Sessions](https://arxiv.org/abs/2606.23654)** · [GitHub](https://github.com/FrontisAI/EnterpriseClawBench) · [Project](https://frontisai.github.io/EnterpriseClawBench/)  
Pushing agent evaluation out of controlled lab settings, this work introduces a benchmark built from authentic, heterogeneous workplace sessions. It directly targets enterprise AI deployment, offering datasets and code for realistic agent testing—56 HF upvotes signal community traction.  
· 4/5

**[CLI-Universe: Towards Verifiable Task Synthesis Engine for Terminal Agents](https://arxiv.org/abs/2606.22883)**  
Terminal agents now have a pathway to higher-quality training data: CLI-Universe proposes a verifiable synthesis engine for building executable tasks, tackling critical gaps in data quality for command-line LLM agents.  
· 4/5

### Practical Multimodal Data Handling

**[DataClaw0: Agentic Tailoring Multimodal Data from Raw Streams](https://arxiv.org/abs/2606.21337)** · [GitHub](https://github.com/vancyland/DataClaw0) · [Project](https://czjdsg.github.io/MakeAnyData/#cases)  
A concrete solution for processing high-entropy, unstructured multimodal input streams—from video, audio, and text—to prepare tailored datasets optimized for both human consumption and post-training AI. Artifact and benchmark available; highly relevant to anyone running or evaluating multimodal agents.  
· 4/5

### Retrieval & Reranking

**[KaLM-Reranker-V1: Fast but Not Late Interaction for Compressed Document Reranking](https://arxiv.org/abs/2606.22807)** · [Project](https://kalm-embedding.github.io/)  
This new reranker tackles the cost-quality tradeoff in large retrieval systems, compressing document representations while maintaining interaction speed and reranking accuracy. 38 upvotes on HF reflect real interest among search and knowledge management practitioners.  
· 4/5

· 2/5

## Insights

- Benchmarks are now moving beyond contrived tasks; authentic, heterogenous, real-world datasets are a critical differentiator.
- The agent stack is maturing: evaluation, planning, and data synthesis tools are converging for meaningful enterprise and terminal agent deployments.
- Multimodal preprocessing is emerging as a key bottleneck—solutions like DataClaw0 address both developer pain points and performance gaps.
- Retrieval/reranking advances focus on speed-quality tradeoffs, crucial for scalable document search and Q&A systems.
