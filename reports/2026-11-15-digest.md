## Main list

### Tools
**[alicebrown323/pro-tools-desktop](https://github.com/alicebrown323/pro-tools-desktop) · 3/5**  
Alice Brown released a Pro Tools 2026 desktop setup with multitrack editing, MIDI sequencing, VST hosting, and a portable mode for Windows 11. Matters if you build audio tooling or need a reference DAW implementation; 342 GitHub stars observed today.

**[Topkiflare74/ai--manus2.0](https://github.com/Topkiflare74/ai--manus2.0) · 3/5**

### Nvidia
**[Run GPU-Powered Black Hole Interferometry with NVIDIA cuPhoton](https://developer.nvidia.com/blog/run-gpu-powered-black-hole-interferometry-with-nvidia-cuphoton/) · 1/5**  
Nvidia introduced cuPhoton for GPU-accelerated black hole interferometry, targeting imaging of microarcsecond-scale structures. Matters if you work on computational imaging or radio astronomy pipelines; lab announcement.

**[Faster Scientific Simulations with New FP64 Algorithms in NVIDIA cuBLAS](https://developer.nvidia.com/blog/faster-scientific-simulations-with-new-fp64-algorithms-in-nvidia-cublas/) · 1/5**  
Nvidia added new FP64 algorithms to cuBLAS for dense linear algebra, accelerating molecular chemistry and materials science workloads. Matters if you maintain HPC simulation stacks on Hopper/Blackwell; lab announcement.

### Dataset
**[google/multimodal-knowledge-agent](https://huggingface.co/datasets/google/multimodal-knowledge-agent) · 2/5**  
Google released a multimodal knowledge-agent dataset covering image-text-to-text, visual QA, and document QA tasks under Apache-2.0. Matters if you train or evaluate multimodal agents; 3,316 downloads and 29 likes observed.

**[Angais/pixel-art-atlas-1.4m](https://huggingface.co/datasets/Angais/pixel-art-atlas-1.4m) · 3/5**  
Angais published a 1.4M-image pixel-art dataset (CC0, Parquet) for text-to-image training, tracked for 7 days with rising traction. Matters if you need large-scale sprite or retro-style image data; 60,255 downloads and 499 likes observed.

### Models
**[higurashi-ai/Haru-4B](https://huggingface.co/higurashi-ai/Haru-4B) · 2/5**  
Higurashi-ai released Haru-4B, a full-duplex speech-to-speech audio-to-audio model (safetensors). Matters if you build real-time voice agents or streaming speech systems; 2,098 downloads and 285 likes observed.

**[Edge0/Edge0-145B-NVFP4](https://huggingface.co/Edge0/Edge0-145B-NVFP4) · 2/5**  
Edge0 released a 145B MoE model quantized to NVFP4 (4-bit) for edge inference, tagged latent-moe and gguf. Matters if you deploy large MoE models on constrained hardware; 41,606 downloads and 278 likes observed.

### Research
**[Advancing science & engineering with Antigravity's /teamwork](https://research.google/blog/advancing-science-engineering-with-antigravitys-teamwork-feature/) · 1/5**
