## Main list

### Retrieval
- [Orca: The World is in Your Mind](https://arxiv.org/abs/2606.30534) · [project](https://orca-wm.github.io/)  
  Orca proposes a general world foundation model, learning a unified latent space from multimodal world signals. It surfaces new benchmarks and artifacts; 169 HF upvotes suggest real traction. If you care about cross-modal world modeling, this is the week’s must-read. · 4/5

- [MemLearner: Learning to Query Context memory for Video World Models](https://arxiv.org/abs/2606.31734) · [project](https://yujiwen.github.io/memlearner/)  
  MemLearner tackles interactive video prediction by dynamically querying relevant context memory, advancing state-of-the-art in video world models. Artifact available and trending (16 HF upvotes). · 4/5

### Other
- [Dockerless: Environment-Free Program Verifier for Coding Agents](https://arxiv.org/abs/2606.28436)  
  A significant step for agentic coding: Dockerless enables validation without containerization, making program verification faster and more scalable. 79 HF upvotes and frontier authorship indicate strong real-world relevance, especially for agent training pipelines. · 4/5

- [BlockPilot: Instance-Adaptive Policy Learning for Diffusion-based Speculative Decoding](https://arxiv.org/abs/2606.31315) · [github](https://github.com/AMAP-ML/BlockPilot)  
  BlockPilot advances speculative decoding—speeding up inference via parallel candidate generation and instance-adaptive policies. The linked repo and 65 HF upvotes signal both access and impact. · 4/5

- [GEAR: Guided End-to-End AutoRegression for Image Synthesis](https://arxiv.org/abs/2606.32039) · [github](https://github.com/Tencent-Hunyuan/GEAR) · [project](https://linb203.github.io/gear)  
  GEAR unifies tokenization and generation for visual models, offering improvements for image synthesis pipelines. Both code and demo available, and trending (25 HF upvotes). · 3/5

- [Introducing GeneBench-Pro](https://openai.com/index/introducing-genebench-pro)  
  OpenAI launches GeneBench-Pro, a robust benchmark suite for genomics and biological AI, grounded in real-world datasets. This fills a major gap for scientific model validation—useful for both academic and applied biology teams. · 3/5

### Dataset
- [nvidia/Qwen3.6-27B-NVFP4 (HF Model)](https://huggingface.co/nvidia/Qwen3.6-27B-NVFP4)  
  NVIDIA’s Qwen3.6-27B-NVFP4 trending on HuggingFace—large model checkpoint for text generation, notable for real deployment relevance. · 3/5

- [LiquidAI/LFM2.5-230M (HF Model)](https://huggingface.co/LiquidAI/LFM2.5-230M)
