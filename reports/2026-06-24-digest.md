## Main List

### Agents

- [Qwen-AgentWorld: Language World Models for General Agents](https://arxiv.org/abs/2606.24597)  
  Alibaba’s Qwen-AgentWorld proposes language-based world models for general agents—a cognitive leap where agents anticipate environment dynamics from observations and actions. The preprint is backed by strong authorship, real results, and 68 HF upvotes. Artifact available. This is foundational for reasoning and planning in complex domains. · 4/5

- [OpenThoughts-Agent: Data Recipes for Agentic Models](https://arxiv.org/abs/2606.24855)  
  OpenThoughts-Agent addresses the underlying data curation challenges in training versatile agentic language models—offering actionable recipes and open artifacts for practitioners. While not yet strongly trending, its practical focus on transparent methods for agentic AI could accelerate broader adoption. · 3/5

- [MobileForge: Annotation-Free Adaptation for Mobile GUI Agents with Hierarchical Feedback-Guided Policy Optimization](https://arxiv.org/abs/2606.19930) · [code](https://github.com/kwai/MobileForge) · [project](https://mobile-forge.github.io)  
  MobileForge enables mobile GUI agents to adapt to target apps without costly manual annotation, using hierarchical feedback and policy optimization. 31 HF upvotes and accessible code make this a practical advance for agent deployment in real-world UX. · 3/5

- [MemGUI-Agent: An End-to-End Long-Horizon Mobile GUI Agent with Proactive Context Management](https://arxiv.org/abs/2606.19926) · [code](https://github.com/kwai/MemGUI-Agent) · [project](https://memgui-agent.github.io/)  
  Tackling reliability for mobile GUI agents, MemGUI-Agent brings proactive context management for long-horizon tasks—critical as agents execute chains of actions across stateful interfaces. 30 HF upvotes and open code support practical use. · 3/5

### Benchmark

- [allenai/olmOCR-bench (HF Dataset)](https://huggingface.co/datasets/allenai/olmOCR-bench)  
  AllenAI’s olmOCR-bench is a new open document OCR benchmark with strong authorship and official evaluation YAMLs. It’s trending on HF and fills a gap for robust, standardized benchmarking of OCR models in document settings. · 4/5

- [NatureBench: Can Coding Agents Match the Published SOTA of Nature-Family Papers?](https://arxiv.org/abs/2606.24530) · [code](https://github.com/FrontisAI/NatureBench) · [project](https://frontisai.github.io/NatureBench/)  
  NatureBench distills 90 tasks from peer-reviewed Nature-family papers as a cross-discipline benchmark, testing if coding agents can achieve or surpass human-published SOTA. This is a definitive testbed for evaluating agentic coding abilities, with 43 HF upvotes and open artifacts. · 4/5

### Other

- [deepfakes/faceswap — Deepfakes Software For All](https://github.com/deepfakes/faceswap)  
  Faceswap remains a dominant deepfake software package, with 55,312 GitHub stars. The artifact continues to serve as a baseline for generative face swapping in research and application. · 3/5

- [Kobaayyy/Awesome-CVPR2026-CVPR2025-ICCV2025-CVPR2024/ECCV2026/ECCV2024-AIGC](https://github.com/Kobaayyy/Awesome-CVPR2026-CVPR2025-ICCV2025-CVPR2024-ECCV2026-ECCV2024-AIGC)  
  A comprehensive repository of SOTA papers and codebases for image generation and computer vision conferences (CVPR/ECCV/ICCV). 671 GitHub stars indicate strong community adoption—useful for staying ahead in computer vision and AIGC developments. · 3/5

- [apple/ml-mdm — Train high-quality text-to-image diffusion models in a data & compute efficient manner](https://github.com/apple/ml-mdm)  
  Apple's ML-MDM is a toolkit for efficient training of text-to-image diffusion models, offering accessible methods for high-quality output even with limited data or compute. 515 GitHub stars show rapid traction among deep learning practitioners. · 3/5

- [krea/Krea-2-Turbo (HF Model)](https://huggingface.co/krea/Krea-2-Turbo)  
  Krea-2-Turbo is a new text-to-image diffusion model trending on HuggingFace—relevant for those tracking open alternatives in generative image synthesis. · 2/5
