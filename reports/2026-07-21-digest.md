## Main list

- [SWE-Pruner Pro: The Coder LLM Already Knows What to Prune](https://arxiv.org/abs/2607.18213) · [code](https://github.com/Ayanami1314/swe-pruner-pro)  
  This research introduces SWE-Pruner Pro, demonstrating that LLM coding agents internally encode relevance signals for context pruning, eliminating the need for an external classifier. The method is validated by a linked repo and is trending on Hugging Face with 60 upvotes. If you’re building or deploying coding agents, this could radically improve context efficiency and simplify workflows. · 4/5

- [HOMIE: Human-object Centric Video Personalization via Multimodal Intelligent Enchancement](https://arxiv.org/abs/2607.18217) · [code](https://github.com/YIYANGCAI/HOMIE) · [project](https://yiyangcai.github.io/homie-page.github.io/)  
  HOMIE tackles the challenge of subject-driven video generation by improving personalization—especially fidelity to humans and their interactions with objects—using multimodal intelligent enhancement. Now available as an open repo and demo, it advances video personalization and stands out for traction on Hugging Face (39 upvotes). · 4/5

- [harry0703/MoneyPrinterTurbo — 利用 AI 大模型和自动化工作流，根据主题或关键词一键生成高清视频。Generate HD short videos from a topic or keyword with an automated AI workflow.](https://github.com/harry0703/MoneyPrinterTurbo)  
  A Python repo with huge velocity (98,446 stars) for generating HD short videos using automated AI workflows based on topics or keywords. The scale of adoption suggests real utility for digital content creators and marketing. · 3/5

- [codeparrot/github-code (HF Dataset)](https://huggingface.co/datasets/codeparrot/github-code)  
  This multilingual code dataset is trending on Hugging Face. Used for training and evaluating language models (text generation, language modeling), it’s a foundational resource for anyone working on LLMs for code. · 3/5

- [pengzhangzhi/Open-dLLM — Open diffusion language model for code generation — releasing pretraining, evaluation, inference, and checkpoints.](https://github.com/pengzhangzhi/Open-dLLM)  
  Open-dLLM ships a diffusion-based language model for code generation, with accessible pretraining, evaluation, inference scripts, and checkpoints. With 645 GitHub stars, it's attracting fast attention in code-centric AI workflows. · 3/5

- [Westlake-AGI-Lab/Awesome-Style-Transfer-with-Diffusion-Models — A curated list of recent style transfer methods with diffusion models](https://github.com/Westlake-AGI-Lab/Awesome-Style-Transfer-with-Diffusion-Models)  
  A well-organized resource for recent style transfer techniques using diffusion models; useful for researchers and practitioners advancing creative AI. 197 GitHub stars in short order marks it as a central repository. · 3/5

- [TypiCore: A Hybrid Active Query Strategy for Class-Incremental Learning on Time Series](http://arxiv.org/abs/2607.17632v1)  
  TypiCore proposes an active query-based strategy for continual learning in time series—addressing the challenge of labeling in real-world streams. Ships a usable artifact alongside new benchmarks, indicating value in dynamic environments like healthcare or manufacturing. · 3/5

- [COVAriance-Induced Fairness Gap Penalty for Subgroup-Fair Clustering](http://arxiv.org/abs/2607.18119v1)  
  A method for fair clustering across multiple sensitive attributes and subgroup definitions, tackling scalability and stability in complex settings. Code artifact included, so it’s ready for applied fairness research and implementation. · 3/5

- [Debate-on-Graph: Reliable and Adaptive Reasoning of Large Language Model on Uncertain Knowledge Graph](http://arxiv.org/abs/2607.17266v1)  
  Elevates LLM question answering on noisy knowledge graphs, adding robust reasoning to reduce hallucinations. Artifact released, promising better reliability for AI assistants leveraging structured knowledge. · 3/5

- [CDIS: Cross-Dimensional Class-Agnostic 3D Instance Segmentation via 2D Mask Tracking and 3D-2D Projection Merging](http://arxiv.org/abs/2607.17778v1)  
  Introduces a class-agnostic approach for 3D instance segmentation of unknown objects—valuable for robotics and navigation in novel environments. Offers new benchmarks and implementation. · 3/5

## Insights

- Code generation and curation tools continue to dominate attention—practicality and artifact availability are clear priorities.
- Video workflows are evolving with both automation (MoneyPrinterTurbo) and personalization (HOMIE), hinting at deeper integration of multimodal AI in content creation.
- Fairness and reliability, especially with subgroup-driven clustering and reasoning over noisy graphs, are emerging as concerns in deployed systems, not purely academic.
- Open benchmarks and datasets are the currency for rapid community adoption; releases without accessible artifacts are notably absent.
