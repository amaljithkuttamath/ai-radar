## Main list

### Benchmarks

**[Few-Shot Learning for Personalised Automated Pain Assessment](http://arxiv.org/abs/2610.09692v1) · 3/5**  
Re-frames personalised pain classification as a few-shot meta-learning problem on the BioVid database. The authors report strong subject-level generalisation where population models fail. Code and splits released. · [paper](http://arxiv.org/abs/2610.09692v1)

**[sk-bench: A Native-First Benchmark for Evaluating LLMs in Slovak](http://arxiv.org/abs/2610.09152v1) · 3/5**  
First native Slovak benchmark (30 datasets, 33 task variants) for a morphologically rich language omitted from multilingual suites. Includes IFEval-SK with adapted instruction checkers and new grammar/morphology resources. 55 models evaluated; best open model trails proprietary APIs by ~15 pts. · [paper](http://arxiv.org/abs/2610.09152v1)

**[LLM4Impact: Integrating Heterogeneous Information for Scientific Impact Prediction](http://arxiv.org/abs/2610.10138v1) · 3/5**  
Evidence-aware method combining semantic, graph, LLM, and temporal representations to predict paper impact at publication time. Injects graph information into a frozen LLM backbone. Beats single-source baselines on citation prediction. · [paper](http://arxiv.org/abs/2610.10138v1)

**[TaoD2C-Bench: Benchmarking MLLMs for Industrial UI Code Generation](http://arxiv.org/abs/2610.10374v1) · 3/5**  
Tests whether MLLMs can convert design images + messy layer metadata into constraint-aware frontend code (React, Flutter, etc.) under target-library rules. Moves beyond visual fidelity to structural and semantic correctness. · [paper](http://arxiv.org/abs/2610.10374v1)

**[PoreML: Data-Driven Framework for Multiphase Flow in Porous Media](http://arxiv.org/abs/2610.10314v1) · 2/5**  
Open-source pipeline unifying 3D data generation, model training, and evaluation for CO₂ storage, fuel-cell, and packaging flows. Addresses scarce time-resolved 3D data with a unified workflow. · [paper](http://arxiv.org/abs/2610.10314v1) · [code](https://github.com/poreml/poreml)

### Agents & streaming video (continuing stories)

**[OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video](https://arxiv.org/abs/2610.01762) · 4/5**  
5th run, traction ~3× since first seen (181★, 233 HF upvotes). Jointly learns query-independent evidence recording and task response through proactive generation — solves the "retain before relevance is known" problem in streaming video LLMs. · [paper](https://arxiv.org/abs/2610.01762) · [code](https://github.com/MCG-NJU/OneStreamer) · [project](https://mcg-nju.github.io/OneStreamer)

**[Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States (PoS)](https://arxiv.org/abs/2610.01415) · 4/5**  
5th run, traction ~2× since first seen (29★, 93 HF upvotes). Inference-time framework that constructs and maintains explicit belief states as the agent's decision context, replacing raw history with a coherent world model. · [paper](https://arxiv.org/abs/2610.01415) · [code](https://github.com/luoyu100/PoS) · [project](https://luoyu100.github.io/projects/progression-of-states/project/)

### Methods

**[LASER: Latent Space Adjoint Matching for Offline RL](http://arxiv.org/abs/2610.08989v1) · 3/5**  
Shows entropy regularization is essential in latent-space offline RL to prevent policy collapse into brittle modes. Adjoint matching in the constrained latent space stabilizes optimization. · [paper](http://arxiv.org/abs/2610.08989v1)

**[Using Small Language Models to Reverse-Engineer ML Pipeline Structures](http://arxiv.org/abs/2610.10261v1) · 3/5**  
Evaluates SLMs for extracting pipeline stages (preprocessing, modeling, etc.) from heterogeneous source code. Outperforms traditional classifiers on evolving ML codebases; suggests SLMs as scalable code-understanding tools. · [paper](http://arxiv.org/abs/2610.10261v1)

**[autotrust/GLM5.3-Flash-E224-DGX-Spark](https://huggingface.co/autotrust/GLM5.3-Flash-E224-DGX-Spark) · 2/5**  
MoE model (GLM-5.3 family) quantized to NVFP4 for DGX Spark deployment. Tags: vLLM, safetensors, MOE. Trending on HF — practical artifact for on-prem MOE serving. · [model](https://huggingface.co/autotrust/GLM5.3-Flash-E224-DGX-Spark)

## Insights

- **Benchmark fragmentation is accelerating** — five new suites in 48h, each targeting a distinct niche (medical, low-resource language, scientometrics, industrial code, scientific simulation). No consolidation in sight; model selection now requires a benchmark battery.
- **Agent memory is converging on explicit belief states** — PoS (carryover) and the new WebFovea/RobotWorld benchmarks both signal that raw history + RAG isn't enough; structured, continually updated world models are becoming the default architecture for long-horizon agents.
- **Streaming video is the new frontier for efficient attention** — OneStreamer (carryover) and GRACE (new) both tackle the "evidence before relevance" problem from different angles (proactive generation vs. latent compression), suggesting a shared research vector.

- **Try**: OneStreamer codebase for any streaming video use case — the proactive memory module is modular and the repo is active (181★, recent commits).
