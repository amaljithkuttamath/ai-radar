## Main list

### Other

- [microsoft/qlib — AI-oriented Quant investment platform](https://github.com/microsoft/qlib)  
Qlib, now with RD-Agent automation, is a full-stack open-source suite for quant investment powered by AI. It supports diverse ML paradigms—supervised learning, market dynamics modeling, and RL—and is trending at over 46,000 GitHub stars, making it the principal toolkit for researchers and practitioners in finance leveraging ML. · 4/5

- [SLAI T-Rex: Full-Parameter Post-training of the DeepSeek-V4 Family on Ascend SuperPOD](https://arxiv.org/abs/2607.20145) · [code](https://github.com/SLAI-AITP/SLAI-T-Rex)  
Extends trillion-parameter MoE post-training from GPU to Huawei's Ascend SuperPOD. Tackles memory and communication bottlenecks for large-scale distributed training, providing strategies for efficient inference and kernel execution—significant for groups bridging to non-NVIDIA hardware. Seen 32 HF upvotes. · 4/5

- [Interpretable Fuzzy Rule-Based Regression Extension for Ex-Fuzzy Library](http://arxiv.org/abs/2607.20277v1)  
Introduces interpretable Mamdani-style fuzzy regression into modern ML workflows. Targets regulated domains needing explainability beyond typical regression, providing artifact and concrete benchmark. · 3/5

- [OSVE: One Step Video Editing with One Step Diffusion Models](http://arxiv.org/abs/2607.19895v1)  
OSVE adapts single-step text-to-image diffusion to video editing, dramatically boosting efficiency while maintaining editability and temporal consistency. Delivers high-quality results with practical speed—potential game-changer for creative and production workflows. · 3/5

- [Membrizard/ml_conformer_generator — Spatially-aware molecule design via Equivariant Diffusion and GCN](https://github.com/Membrizard/ml_conformer_generator)  
Early-stage but trending tool for spatially-informed molecule design, leveraging equivariant diffusion and graph neural networks. Useful for computational chemistry, seen 58 GitHub stars. · 2/5

### Benchmark

- [Beyond Relevance-Centric Retrieval: Rubric-Oriented Document Set Selection and Ranking](https://arxiv.org/abs/2607.19747) · [code](https://github.com/Rubric4Setwise/Rubric4Setwise) · [project](https://rubric4setwise.github.io/)  
Proposes a new method and benchmark for document set selection, focusing on rubric-oriented ranking instead of relevance alone. Models inter-document interactions (redundancy, conflict, complementarity), filling a gap in agent evaluation. Artifact and project site available, 21 HF upvotes. · 3/5

- [HalluTruthQA: Benchmark for Hallucination Detection, Localization, and Explanation in Arabic QA](http://arxiv.org/abs/2607.20219v1)  
Provides fine-grained labels for hallucination in Arabic QA, enabling detection, localization, and explanation—not just response-level, but exact erroneous content and why. Serves multilingual and factuality research. · 3/5

- [Hypothesis-and-Refinement Learning of Organic Structures from Multimodal Spectroscopic Data](http://arxiv.org/abs/2607.19816v1)  
Addresses the inverse problem of molecular structure discovery from underdetermined multimodal spectroscopic data. Combines hypothesis generation and iterative refinement—a step forward in automated molecular science. · 3/5

- [LKValues: Aligning Large Language Models with Sri Lankan Societal Values](http://arxiv.org/abs/2607.20410v1)  
Benchmark for value alignment addressing cultural bias in LLMs, contextualized for Sri Lankan norms and local language. Enables more equitable LLM evaluation and tuning in multilingual, non-Western settings. · 3/5

- [PRO-LONG: Programmatic Memory Enables Long-Horizon Reasoning](http://arxiv.org/abs/2607.20064v1)  
Agent harness introducing structured memory for long-horizon tasks, directly targeting continual learning benchmarks and AGI evaluation. Artifact included, relevant for teams pushing agent autonomy and reasoning. · 3/5
