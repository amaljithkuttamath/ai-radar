## Main list

### Solarwm

**[SolarWM: Open Data and Scalable Training for Long-Horizon Video World Models](https://arxiv.org/abs/2609.02886) · [code](https://github.com/Junchao-cs/SolarWM) · [project](https://junchao-cs.github.io/SolarWM-Web/) · 4/5**  
An end-to-end open stack for video world models: heterogeneous data curation, scalable training across backbone architectures, and long-horizon rollout. 380 GitHub stars, 138 HF upvotes — third radar run, traction still rising (Δ+3.1×). The repo includes dataset tooling, training configs, and evaluation harnesses; the project page shows interactive demos. If you're building or benchmarking world models, this is the current reference implementation.

**[StreamPI: Streaming Multimodal Temporal Modeling for Vision-Language-Action Models](https://arxiv.org/abs/2608.26067) · [code](https://github.com/hku-sail/StreamPI) · [project](https://happinesslz.github.io/projects/StreamPI/) · 4/5**  
Adds streaming temporal reasoning to single-frame VLA policies (pi0.5-class), enabling precise spatial perception over history. 204 stars, fifth run, traction Δ+2.9×. The framework is model-agnostic — plug it into existing VLA checkpoints — and the project page includes real-robot rollouts. Directly relevant if you're deploying manipulation policies that need to remember.

**[mertizci/noai-watermark — Remove invisible AI watermarks (SynthID, StableSignature, TreeRing) and strip AI metadata from images](https://github.com/mertizci/noai-watermark) · 4/5**  
CLI + Python toolkit that strips SynthID, StableSignature, TreeRing watermarks and EXIF AI metadata. 176 stars, fourth run, traction flat (Δ+1%). Practical for dataset cleaning, provenance auditing, or red-teaming watermark robustness. No paper — just a working tool with clear scope.

**[DavidAU/Qwen3.8-27B-TURBO-Fable-Cold-Fusion-735-882-Heretic-Uncensored-NEO-CODER-MAX-MTP-GGUF](https://huggingface.co/DavidAU/Qwen3.8-27B-TURBO-Fable-Cold-Fusion-735-882-Heretic-Uncensored-NEO-CODER-MAX-MTP-GGUF) · 3/5**  
Merged 27B GGUF (Unsloth-quantized) combining Fable, Cold-Fusion, Heretic, NEO-CODER, and MTP checkpoints. Trending on HF; no benchmarks published yet. Worth a quick eval if you need a single uncensored coding/instruct model at 27B, but treat as experimental until independent evals land.

**[facebook/mms-300m](https://huggingface.co/facebook/mms-300m) · 2/5**  
Massively Multilingual Speech (MMS) 300M-parameter wav2vec2 checkpoint. Trending on HF; part of Meta's 1,000+ language coverage push. Useful if you need a compact multilingual ASR/TTS backbone — smaller than the 1B/2B MMS variants, easier to deploy on edge.

**[njgymb/diffusers-sculptor — Efficient Stable Diffusion Fine-Tuning Framework 2026](https://github.com/njgymb/diffusers-sculptor) · 2/5**  
Lightweight, config-driven SD fine-tuning pipeline (LoRA, DreamBooth, textual inversion). 56 stars, trending on GitHub. Cleaner abstraction than raw diffusers scripts if you run frequent SD adaptation experiments; still early, docs thin.

## Insights

- **Video world models are consolidating around open, full-stack releases** — SolarWM and StreamPI both ship data prep, training, and eval, not just a paper. The field is moving from "here's an architecture" to "here's a reproducible pipeline."
- **Agent memory / long-horizon reasoning is a sustained multi-week theme**, not a flash — 10 story-arc items, several now at 7–9 runs. The convergence: working-memory architectures, recursive self-distillation, and streaming temporal modeling.
- **Practical tooling (watermark stripping, SD fine-tuning configs) scores as high as research papers** when it ships working code and gets real GitHub traction. The radar's scoring correctly surfaces this.
- **HF trending models/datasets are noisy** — the two new HF models and two datasets this window are mostly "newly uploaded, trending tag" without benchmarks or community validation. They land in watch-list, not main list.
