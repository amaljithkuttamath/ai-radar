## Main list

### Other

- [AREX: Towards a Recursively Self-Improving Agent for Deep Research](https://arxiv.org/abs/2607.21461) · [GitHub](https://github.com/VectorSpaceLab/arex-model) · [Project](https://vectorspacelab.github.io/arex-model/)  
  Recursively self-improving agent architecture targeting deep research tasks. The system exploits a discovery-verification asymmetry to enable tractable constraint-wise checks, advancing agentic autonomy. 78 HF upvotes, real repo and project page. High novelty for recursive improvement in agent design. · 4/5

- [Visual Contrastive Self-Distillation](https://arxiv.org/abs/2607.21556) · [GitHub](https://github.com/joliang17/VCSD) · [Project](https://joliang17.github.io/VisualCSD/)  
  On-policy self-distillation method that sidesteps external teachers by introducing privileged visual cues, enabling stronger learning signals for vision models. 36 HF upvotes and code. Stands out for methodologically novel self-distillation. · 4/5

- [KalyanKS-NLP/llm-engineer-toolkit: Curated list of 120+ LLM libraries](https://github.com/KalyanKS-NLP/llm-engineer-toolkit)  
  One-stop repository listing over 120 libraries for LLM engineering, trending rapidly (10,682 GitHub stars). Useful reference for both quick ramp-up and evaluating ecosystem changes. · 3/5

- [When Trivia Is Not Trivial: Everyday Knowledge Failures in Multilingual LLMs](http://arxiv.org/abs/2607.21445v1)  
  Introduces TriviaRoomQA—a benchmark probing common knowledge gaps in multilingual LLMs, with artifacts released. Useful for anyone tracking evaluation weaknesses and dataset biases. · 3/5

- [GlucoTune: Unified Framework for Blood Glucose Preprocessing, Forecasting, and Benchmarking in Diabetes](http://arxiv.org/abs/2607.21117v1)  
  End-to-end framework standardizing blood glucose data prep and prediction, tackling reproducibility and comparability in medical AI. Artifacts and protocols are made available. · 3/5

- [Rushes: Human Preference Dataset for Pluralistic Alignment](http://arxiv.org/abs/2607.20767v1)  
  New dataset for pluralistic human preference structures in interactive narrative environments, supporting nuanced alignment research. · 3/5

- [From Evaluation to Optimisation: Hierarchy-Aware Training Signals for CWE Prediction in Python](http://arxiv.org/abs/2607.21069v1)  
  Validates taxonomy-aware penalties as training signals for vulnerability prediction, delivering concrete gains and artifacts. Immediate relevance for security-focused ML workflows. · 3/5

- [poolside/Laguna-S-2.1-NVFP4 (HF Model)](https://huggingface.co/poolside/Laguna-S-2.1-NVFP4)  
  Trending release on HuggingFace: conversational text-generation model tagged for vllm and safetensors formats. · 2/5

### Evaluation

- [Multimodal Pretraining for Generalizable EEG Representation Learning](http://arxiv.org/abs/2607.21384v1)

- [MSBraM: Multi-scale Self-supervised Brain Foundation Model for Hierarchical EEG Dynamics Learning](http://arxiv.org/abs/2607.21402v1)  
  Tackles the multi-scale temporal complexity of EEG signals with hierarchical self-supervised learning—new foundation model released. · 3/5
