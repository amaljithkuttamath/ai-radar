## Main list

**1. alibaba-pai/MiniMax-H3-Fun-Controlnet-Union** — A unified ControlNet for MiniMax’s H3 video model supporting text-to-video, image-to-video, and video-to-video with multiple control signals (canny, depth, pose, etc.). From Alibaba’s PAI team; trending on HF. [model](https://huggingface.co/alibaba-pai/MiniMax-H3-Fun-Controlnet-Union) · 3/5

**2. Discovering Relationships in Data Lakes Using Large Language Models** — ColRel, a two-stage method that builds column embeddings from ingestion-time metadata and data, then uses business dictionaries to decode coded/abbreviated schema labels in ERP datasets. Beats baselines on public benchmarks and a real industrial ERP lake. [paper](http://arxiv.org/abs/2608.26750v1) · 3/5

**3. FedCMAPSS: A Benchmark for Federated Learning in Remaining Useful Life Estimation** — First standardized FL benchmark for prognostics (RUL prediction) built on NASA C-MAPSS. Defines heterogeneous client splits, communication budgets, and non-IID sensor drift scenarios — filling a gap where prior FL work had no common evaluation ground. [paper](http://arxiv.org/abs/2608.26433v1) · 3/5

**4. Subgraph Filtering for Fair Graph Neural Networks (SF-GNN)** — Architecture-agnostic plug-in that removes biased message-passing pathways at the subgraph level instead of constraining global representations. Improves fairness metrics across Cora, Citeseer, and PubMed with <2% accuracy drop; no retraining of the base GNN required. [paper](http://arxiv.org/abs/2608.26437v1) · 3/5

**5. Behavior2Trip: Personalized Travel Planning via User Behavior Trajectory** — New task: infer travel preferences from passive behavioral logs (clicks, dwell time, past bookings) rather than explicit dialogue. Dataset + agent framework that outperforms instruction-only and clarification-based baselines on personalization metrics. [paper](http://arxiv.org/abs/2608.26807v1) · 3/5

**6. Zero-Shot Self-Orchestration with Ledger-Based Control for LLM Coding** — Clean ablation: adding a manager-worker scaffold over a shared filesystem (no training, no per-benchmark tuning) across 9 models (9B–2.8T params). The scaffold *itself* yields consistent gains on HumanEval+/MBPP+; token budget and tool calls are held constant. [paper](http://arxiv.org/abs/2608.26480v1) · 3/5

**7. MedFG-VQA: Low-Frequency Memory and Graph Attention for Lightweight Medical VQA** — Sub-1B parameter model using a DCT-based frequency-memory bank and graph-enhanced cross-attention to align visual/textual features. Matches or beats 7B+ VLMs on VQA-RAD, SLAKE, and PathVQA while running at ~15 FPS on a single A100. [paper](http://arxiv.org/abs/2608.26848v1) · 3/5

**8. faunix/Qwen3.8-27B-Distillation-40K** — 40K distilled reasoning traces from Qwen3-27B (Apache-2.0, Parquet). Useful seed for training smaller reasoning models or analyzing CoT patterns. [dataset](https://huggingface.co/datasets/faunix/Qwen3.8-27B-Distillation-40K) · 2/5

**9. zai-org/GLM-5.3** — Z.ai’s latest MoE (GLM-MoE-DSA) release on HF; conversational text-generation weights in safetensors. No benchmark report yet; treat as early access. [model](https://huggingface.co/zai-org/GLM-5.3) · 2/5
