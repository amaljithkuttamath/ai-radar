## Main list

### RRSI: Regularized Recursive Self-Improvement of Agent Harnesses · 4/5
[Paper](https://arxiv.org/abs/2609.24972) · [Code](https://github.com/google-research/rrsi) · [Project](https://regularized-rsi.com/)  
Google Research introduces a regularized recursive self-improvement (RRSI) loop that iteratively proposes and selects component-wise edits to an agent's harness — prompts, control flow, tooling, memory — while penalizing overfitting to training tasks. The method shows sustained out-of-distribution gains where prior RSI approaches collapsed. 130 HF upvotes; repo and project page live today. **Read the paper, then try the repo if you build agent scaffolding.**

### LynnReal-Omni: Native multi-modal Video Generation for Agentic Visual Workflows · 4/5
[Paper](https://arxiv.org/abs/2609.15863) · [Code](https://github.com/LynnReal-AI/LynnReal-Omni)  
Seventh run on the radar; traction up ~293% since Sept 15 (214 ★, 55 HF ↑). A video diffusion model that consumes explicit 3D scene references, editable assets, and executable game states to achieve stable, controllable generation — addressing the drift and stochasticity that plague pure prompting. The repo ships inference code and assets. **Track if you need controllable video for agentic workflows; the traction curve says adoption is accelerating.**

## Insights
- **Recursive self-improvement is specializing**: RRSI (harness-level), RSIAgent (exploration-level), ScienceBuddy (scientific-agent-level) — each attacks a different layer of the stack. The pattern suggests RSI is becoming a design pattern, not a monolith.
- **Video world models are converging on "agentic control"**: LynnReal-Omni, WorldCrafter, VideoGen-Agent all frame generation as an agent acting in a structured (3D/game) environment rather than pure pixel prediction.
- **Benchmarks are stabilizing as infrastructure**: GAIA at 11 runs, GameHorizon arriving new — evaluation is becoming the fixed layer atop which model/harness innovation competes.
- **Diffusion-for-robotics literature is consolidating**: The mbreuss repo (920 ★) signals the field has enough volume to need a dedicated map.
