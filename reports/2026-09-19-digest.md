## Main list

### 1. LynnReal-Omni: Native multi-modal Video Generation for Agentic Visual Workflows · 4/5
[Paper](https://arxiv.org/abs/2609.15863) · [Code](https://github.com/LynnReal-AI/LynnReal-Omni)  
**Continuing story — 4th run, traction 51 HF upvotes → 194 GitHub stars (2.8× since Sep 15).** A video diffusion model designed for *agentic* control: it consumes explicit 3D scene references, editable layouts, or executable game states to stabilize long-horizon generation and object fidelity. The repo is live and the team is actively iterating — this is the rare video model built for programmatic steering, not just prompting.

### 2. prism-ml/Ternary-Bonsai-2-27B-mlx-2bit · 3/5
[Model](https://huggingface.co/prism-ml/Ternary-Bonsai-2-27B-mlx-2bit)  
**New.** 2-bit ternary quantization (Hadamard-transformed Qwen3-5B backbone) of the Bonsai-2 27B model, packaged for Apple Silicon via MLX. The prism-ml group has been pushing extreme quantization frontiers; this drops weights to ~7 GB with claimed minimal quality loss. Worth a local test if you run MLX workloads and need a 27B-class model that fits in unified memory.

### 3. convaiinnovations/laya · 2/5
[Model](https://huggingface.co/convaiinnovations/laya)  
**New.** A text-classification head trained with RLCD (Reinforcement Learning from Calibrated Decisions) — the "System One" fast-path classifier for the Convin AI stack. It outputs calibrated confidence scores, not just logits, which matters for routing/cascading pipelines. Early traction on HF; no public benchmark yet, so treat as promising but unverified.

## Insights

- **Agentic video is the only theme with compounding traction.** LynnReal-Omni, BVB, LynnReal-Omni, Mask Forcing, and Dream-RSI all cluster around *controllable, programmatic video* — and every one is on a multi-run growth streak. The field has moved from "generate clips" to "drive a simulator."
- **Recursive self-improvement papers are forming a durable mini-paradigm.** RSIAgent, ScienceBuddy, Dream-RSI, Miles, and Omni Interaction Agent all explore agents that rewrite their own policies/environments. Eight-run streaks for Miles and Omni suggest this isn't a flash.
- **Quantization-for-MLX is a quiet but real niche.** prism-ml's 2-bit ternary Bonsai-2 joins a string of Apple-Silicon-targeted releases (MLX-LM, MLX-Whisper, etc.) that never hit HN front page but accumulate steady GitHub stars from local-LLM practitioners.
- **Benchmarks and datasets from major labs (GAIA, PhysicalAI, MilleMiglia) land with a thud.** Strong authorship + usable artifact ≠ adoption. Community traction requires a *task* people are already trying to solve.
