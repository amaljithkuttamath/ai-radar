## Main list

### SolarWM: Open Data and Scalable Training for Long-Horizon Video World Models · 4/5
[Paper](https://arxiv.org/abs/2609.02886) · [Code](https://github.com/Junchao-cs/SolarWM) · [Project](https://junchao-cs.github.io/SolarWM-Web/)  
Fourth run tracking this — stars 396 → 411, HF upvotes 137 → 141. A fully open foundation for interactive video world models: heterogeneous data curation, unified training across video backbones, and long-horizon inference. The project page shows controllable generation demos. Continuing story — traction still climbing.

### StreamPI: Streaming Multimodal Temporal Modeling for Vision-Language-Action Models · 4/5
[Paper](https://arxiv.org/abs/2608.26067) · [Code](https://github.com/hku-sail/StreamPI) · [Project](https://happinesslz.github.io/projects/StreamPI/)  
Sixth run — stars 207 → 213. Retrofits single-frame VLA policies (like pi0.5) with a streaming temporal module that retains past observations for precise spatial reasoning. Real robot evals show measurable gains on manipulation tasks requiring memory. Continuing story — traction still climbing.

### urchade/GLiNER — Generalist Lightweight NER · 3/5
[GitHub](https://github.com/urchade/GLiNER) — 3,613 stars  
Bidirectional transformer that extracts arbitrary entity types from text without retraining — prompt it with the schema you need. Already packaged for HF Transformers, ONNX, and spaCy. Practical drop-in for document processing pipelines where schema changes frequently.

### OpenVDN/vdn-minimax-h3 · 3/5
[Model](https://huggingface.co/OpenVDN/vdn-minimax-h3)  
Community finetune of MiniMax's H3 text-to-video base model, distributed via diffusers-compatible safetensors. No paper, but the base model is a recent frontier release — this makes it runnable locally. Watch for evals against the upstream checkpoint.

## Insights
- **Video world models are bifurcating**: SolarWM and EchoWM pursue open, scalable foundations; EditaLive! and StreamPI target controllable editing and robotics integration respectively. The cluster is deepening rather than consolidating.
- **Agent memory architectures are converging on streaming + externalized state**: StreamPI, Recursive Experiential-Working Memory, and JIT-Agent all treat context as an evolving artifact, not a fixed window.
- **Watermark removal tooling reaching mainstream GitHub trending** signals that provenance/invisibility tensions are now an operational concern, not just academic.

## Action items
- **Try** — SolarWM codebase for long-horizon video generation; the project page has interactive demos and the repo is active.
- **Read** — StreamPI paper if you work on VLA/robotics; the temporal module is architecture-agnostic and could retrofit existing policies.
- **Track** — GLiNER for any NER pipeline where entity schemas change; the bidirectional approach avoids retraining cycles.
- **Monitor** — noai-watermark adoption; if it gains traction in production workflows, expect platform responses (watermark hardening, detection arms race).
