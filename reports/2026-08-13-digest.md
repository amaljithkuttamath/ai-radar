## Main list

### Evaluation Benchmarks

**[SWE-Bench ProMax: Benchmarking Agents on Large-Scale Multilingual Code Refactoring](https://arxiv.org/abs/2608.09802) · [dataset](https://huggingface.co/datasets/swe-bench-promax/SWE-Bench-ProMax) · 4/5**  
A multilingual refactoring benchmark built after an audit found ~60% of SWE-bench Verified instances have flawed tests. 125 HF upvotes on day one; the dataset is live on Hugging Face. Critical for anyone trusting agent coding evals.

**[Advancing MLLM-based UAV Image Understanding and Reasoning](http://arxiv.org/abs/2608.11738v1) · 3/5**  
UAVQA-Bench: 1,500 human-annotated QA pairs across 13 public UAV datasets, six capabilities. Includes a training-free multi-agent system that outperforms single-model baselines. Frontier-group authorship, artifact released.

**[Cross-Corpus Evaluation of Generalizable Vulnerability Detection in IoT Firmware](http://arxiv.org/abs/2608.11492v1) · 3/5**  
IoTVulBench: human-verified, contamination-screened firmware vulnerability benchmark from GitHub repos. Addresses the synthetic-dataset gap in cross-corpus generalization. Code and data released.

**[FrontierFinance: A Challenging Benchmark for Measuring Frontier Intelligence of Finance Agents](http://arxiv.org/abs/2608.11683v1) · 3/5**  
220 expert-crafted investor-workflow queries with 11,543 source-attributed rubrics. Current frontier models score poorly on the full workflow; the benchmark exposes reasoning gaps that extraction benchmarks miss.
