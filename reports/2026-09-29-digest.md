## Main list

### 1. GameHorizon Suite: Multi-Horizon Data and Evaluation in Gameplay  
[Paper](https://arxiv.org/abs/2609.25001) · [Code](https://github.com/TencentARC/GameHorizon) · [Project](https://gamehorizon-suite.github.io/) · 4/5  
Continuing story (7th run, stars 360 → 372). A unified benchmark suite spanning 20+ games with language instructions, offline evaluation, and multi-horizon tasks — planning, control, and visual reasoning in one package. The repo and leaderboard are live; traction keeps compounding.

### 2. LynnReal-Omni: Native Multi-modal Video Generation for Agentic Visual Workflows  
[Paper](https://arxiv.org/abs/2609.15863) · [Code](https://github.com/LynnReal-AI/LynnReal-Omni) · 4/5  
Continuing story (13th run, stars 241 → 248). Video diffusion with explicit 3D/scene control for long-horizon coherence. Ships a full inference pipeline; the "agentic visual creation" framing is unusual — it treats video gen as a tool-use problem, not just prompting.

### 3. apple/LensVLM-9B  
[Model](https://huggingface.co/apple/LensVLM-9B) · 3/5  
Apple's 9B vision-language model built on Qwen3.5, targeting long-context image-text reasoning. Weights are up (safetensors, transformers-compatible); no paper yet, but the architecture suggests they're pushing context length for document/video understanding.

### 4. Reference-Grounded Data Curation for Instruction-Following Thai-English Machine Translation  
[Paper](http://arxiv.org/abs/2609.34770v1) · 3/5  
Two-phase pipeline: extract constraints from a reference translation that already satisfies them, then filter by Instruction-Following Difficulty. Beats general IF augmentation on terminology, formatting, and register compliance without quality trade-off. Dataset released.

### 5. CARDAMOM: A Micro-Dialectal Arabic Speech Dataset for ASR  
[Paper](http://arxiv.org/abs/2609.34481v1) · 3/5  
~40 hours across 21 micro-dialects from 6 countries, community-curated by native speakers. Annotated for code-switching and perceived gender. Fills a granular evaluation gap — most Arabic ASR benchmarks stop at country-level dialects.

### 6. GUIDE-FBO: Guidance via Uncertainty Intervention and Distributional Exchange for Federated Bayesian Optimization  
[Paper](http://arxiv.org/abs/2609.35038v1) · 3/5  
Agents exchange compact GP posterior distributions over optima locations instead of raw observations. Server merges and reweights before returning a global guide. Cuts communication while handling task heterogeneity — practical for distributed black-box optimization.

### 7. d-OPD: Future-Aware On-Policy Distillation for Block Diffusion Language Models  
[Paper](http://arxiv.org/abs/2609.35362v1) · 3/5  
Adapts autoregressive LLMs to block diffusion (parallel token denoising per block) via on-policy distillation that accounts for future blocks. Addresses the exposure bias that naive distillation introduces. Code released; relevant if you're tracking non-AR decoding.

### 8. unsloth/Qwen-Image-2.1-GGUF  
[Model](https://huggingface.co/unsloth/Qwen-Image-2.1-GGUF) · 3/5  
Quantized GGUF release of Qwen-Image 2.1 via Unsloth. Drop-in for llama.cpp / ComfyUI / diffusion pipelines. No paper, but the quantization recipe is battle-tested — useful immediately for local image-gen workflows.

### 9. Token-Disentangled Latent Test-Time Scaling for Vision-Language Reasoning  
[Paper](http://arxiv.org/abs/2609.35228v1) · 3/5  
Refines hidden states at inference per token role (visual-evidence vs. reasoning-uncertain tokens) instead of a global scalar. Improves VQA and multimodal reasoning benchmarks without retraining. Inference-time only; easy to try on existing MLLMs.

### 10. AlphaPareto: Formulaic Alpha Discovery with LLM-Guided Multi-Objective RL  
[Paper](http://arxiv.org/abs/2609.34188v1) · 3/5  
Treats alpha pooling as non-stationary MDP; uses LLM to propose formulas, RL to optimize predictive power + diversity + turnover. Outperforms single-objective baselines on real market data. Code released — rare quant paper with usable artifacts.

## Insights

- **Quantized multimodal models are shipping faster than papers** — Unsloth's Qwen-Image GGUF and Apple's LensVLM-9B both landed as runnable weights first; the paper (if any) follows.  
- **Agentic benchmarks are converging on "multi-horizon + offline eval"** — GameHorizon, BVB, and Qwen-Planner-Agent all stress long-horizon planning with reproducible metrics, moving past single-turn chat eval.  
- **Distillation is specializing by architecture** — d-OPD for block diffusion, multi-teacher OPD for domain normalization, Harness-Zero for agent harnesses — each targets a specific student architecture's failure mode.  
- **Dialect/language granularity is the new evaluation frontier** — CARDAMOM (21 Arabic micro-dialects) and the Thai-English IF-MT work both treat sub-population variance as the signal, not noise.
