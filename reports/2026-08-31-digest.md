## Main list

**[candle-org/MindAct](https://github.com/candle-org/MindAct) · 3/5** — 920 GitHub stars. A compatibility layer that lets you run any Hugging Face Transformers or Diffusers model on Huawei's MindSpore framework without code changes. The artifact is the whole value prop: drop-in replacement, acceleration included. If you're deploying on Ascend hardware or evaluating non-NVIDIA stacks, this is the practical bridge. [code](https://github.com/candle-org/MindAct)

**[deepseek-ai/DeepSeek-V4-Flash-Vision-Exp](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp) · 3/5** — DeepSeek's new vision-language model (image-text-to-text) released under MIT license with safetensors weights. Tags indicate `deepseek_v4` architecture; it's an experimental "Flash" variant, so expect speed optimizations over the base V4. Worth a quick eval if you need a permissive-license VL model today. [model](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp)

**[nyu-mll/glue](https://huggingface.co/datasets/nyu-mll/glue) · 3/5** — The GLUE benchmark dataset still trends on Hugging Face (task categories: text-classification, NLI, semantic-similarity, sentiment). No new science here, but its persistent traction signals that baseline evaluation on classic NLU tasks remains a common first step for model developers. [dataset](https://huggingface.co/datasets/nyu-mll/glue)

**[pipecat-ai/phonellm-alpha-1](https://huggingface.co/pipecat-ai/phonellm-alpha-1) · 2/5** — Mixture-of-experts model from the Pipecat team (tags: `nemotron_h`, `mixture-of-experts`, `transformers`). Released as safetensors with transformers config. Early alpha; the MoE architecture and Pipecat's voice-agent framing make it a Track item for real-time voice pipelines. [model](https://huggingface.co/pipecat-ai/phonellm-alpha-1)
