### Main list

#### Video World Models
**[SolarWM: Open Data and Scalable Training for Long-Horizon Video World Models](https://arxiv.org/abs/2609.02886) · [code](https://github.com/Junchao-cs/SolarWM) · [project](https://junchao-cs.github.io/SolarWM-Web/) · 4/5**  
A reconfigurable multitask framework that decouples data preparation from model-specific training, letting you mix heterogeneous video sources (different temporal scales, camera geometries, caption styles) and swap video backbones without re-engineering the pipeline. Ships a full open-source stack — data curation, training recipes, and inference tooling — backed by frontier-group authorship and 117 HF upvotes in 48h.

**[simchowitzlabpublic/nano-world-model](https://github.com/simchowitzlabpublic/nano-world-model) · 3/5**  
Minimalist, batteries-included repository for world-model research: clean implementations of core architectures (Dreamer, IRIS, STORM), standardized benchmarks, and reproducible training loops. 724 GitHub stars signal strong community pull for a "just works" codebase in this space.

**[StreamPI: Streaming Multimodal Temporal Modeling for Vision-Language-Action Models](https://arxiv.org/abs/2608.26067) · [code](https://github.com/hku-sail/StreamPI) · [project](https://happinesslz.github.io/projects/StreamPI/) · 4/5**  
*Continuing story — 3rd run, 181 → 181 stars.* Equips single-frame VLA policies (e.g., π0.5) with a streaming temporal encoder that maintains a compressed history of past observations, enabling precise spatial reasoning over long horizons. Real robot experiments show measurable gains on manipulation tasks requiring memory; 181 GH stars and 19 HF upvotes confirm traction.

#### Long-Context & Memory
**[Trace as State: Reasoning Traces as Conditional States for Long-Context Transformers](http://arxiv.org/abs/2609.02702v1) · 3/5**  
Formalizes the mismatch: causal Transformers see condition-last, but long-context reasoning often needs condition-first. Fix: run the model once to collect a reasoning trace, then prepend that trace as a "conditional state" on a fresh pass so earlier-derived info guides rereading. Frontier authorship + usable artifact; matches focus on long-context efficiency.

**[The Memory Trust Gap: Capability-Dependent Failures in Persistent-Memory Agents](http://arxiv.org/abs/2609.01852v1) · 3/5**  
Controlled study on Qwen3 0.6B–8B: as capability rises, agents *over-trust* stale stored facts even when an authoritative tool contradicts them. The failure is not confusion — it's misplaced confidence. Frozen benchmark with Benefit/Safety suites; artifact released. Critical signal for anyone building personalized agents with persistent memory.

**[Post-Training Ternarization of Qwen3-4B](http://arxiv.org/abs/2609.01962v1) · 3/5**  
End-to-end weight-only conversion of Qwen3-4B-Instruct to 1.58-bit (ternary) via KOTMS rotation + E2M-ATQ + GPTQ-style error compensation. Reports effective bit accounting, capability retention, perplexity, and calibration — not just a nominal bit claim. Artifact available; matches throughput focus.

#### Agent Reliability
**[Loom: Weaving Diagnostic Strands into Free-Text Consensus via Embedding-Space Reweighting](http://arxiv.org/abs/2609.02649v1) · 3/5**  
Neuro-symbolic framework for real-world root-cause analysis: extracts "diagnostic strands" from logs/traces, reweights them in embedding space, and generates free-text consensus. Bridges weak supervision's rigor with LLM expressivity. Deployed in production RCA; frontier authorship + artifact.

**[Diagnosing with Insights: Structured Analysis of Agent Failures via Behavioral Abstractions](http://arxiv.org/abs/2609.02371v1) · 3/5**  
AGENTSCOPE abstracts long agent trajectories into behavioral patterns (loops, hallucinations, tool misuse) and uses neuro-symbolic reasoning to pinpoint failure modes. Beats pure-LLM judges on reliability. Artifact released; matches agents focus.

**[Fine-Grained Anomaly Perception in Wild UGC-Enhanced Images](http://arxiv.org/abs/2609.02529v1) · 3/5**  
New task + dataset + Difference-Fusion framework for detecting localized artifacts (face warp, text corruption, texture loss) introduced by enhancement pipelines on UGC. Existing IQA metrics miss these; this work defines the perceptual anomaly taxonomy and a detector that localizes them. Frontier group + artifact.
