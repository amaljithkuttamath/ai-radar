## Main list

### HarnessEval-W: Agentifying the Evaluation of Visual Worlds · 4/5
[Paper](https://arxiv.org/abs/2608.16859) · [Code](https://github.com/MirroS-Lab/HarnessEval-W) · [Project](https://mirros-lab.github.io/HarnessEval-W)  
A benchmark that replaces scalar scores with an *agent* evaluator — it watches world-model rollouts and reasons through whether physics, causality, and state transitions hold. The evaluator itself is an LLM agent that produces natural-language justifications for every violation it flags. 256 GitHub stars and 123 HF upvotes since Aug 18; traction still rising (+3.1×). If you build or test world models, this is the evaluation layer you've been missing. **Continuing story — 7th run, traction accelerating.**

### Embodied-Navigator: Point, Think, Memorize, and Align for Efficient Navigation · 4/5
[Paper](https://arxiv.org/abs/2608.17512) · [Code](https://github.com/ZJU-OmniAI/Embodied-Omni) · [Project](https://zju-omniai.github.io/Embodied-Navigator/)  
TAMP-Nav reframes VLM-based navigation: instead of forcing the model into discrete action tokens misaligned with its 2D pre-training, it lets the VLM *point* (2D keypoints), *think* (chain-of-thought), *memorize* (semantic topo map), and *align* (cross-modal consistency). 222 stars, 51 HF upvotes in 6 runs; traction up +3×. Strong signal for anyone deploying VLMs in robotic or sim-to-real loops. **Continuing story — 6th run, traction accelerating.**

### ScrapeGraphAI/Scrapegraph-ai — AI-native web scraping · 3/5
[Repo](https://github.com/ScrapeGraphAI/Scrapegraph-ai) — 29.8k stars  
LLM-driven scraping pipeline: you describe what you want in natural language, it builds the extraction graph (handles pagination, dynamic content, anti-bot). Not a research artifact — a production-grade tool that's gone viral. Worth a try if you still hand-write BeautifulSoup/Playwright selectors.

### ornith-ai/Ornith-1.5-9B — Qwen3.5-based VLM · 3/5
[Model](https://huggingface.co/ornith-ai/Ornith-1.5-9B)  
9B parameter vision-language model on Qwen3.5 backbone, safetensors, conversational + image-text-to-text. Trending on HF but no public benchmark numbers yet — treat as a candidate for multimodal fine-tuning, not a drop-in replacement for frontier VLMs.

### incoai/Qwen3.8-27B-DFlash2 — Speculative-decoding + block diffusion · 3/5
[Model](https://huggingface.co/incoai/Qwen3.8-27B-DFlash2)  
27B hybrid combining DFlash2 speculative decoding with block-diffusion token generation. Novel inference-time architecture; no released benchmarks. Interesting if you're exploring non-autoregressive decoding paths at scale.

## Insights

- **Evaluation is eating the stack.** The two highest-signal items are *meta-tools*: an agent that evaluates world models, and a navigation framework that evaluates its own reasoning. The community is converging on "eval as agent" as the path past scalar benchmarks.
- **Viral tools ≠ research breakthroughs.** ScrapeGraphAI's 30k stars dwarf the research items, but it's an application-layer utility — distinct from the frontier-method signal. Keep the categories separate in your reading stack.
- **Multilingual/legal data is surfacing quietly.** The Turkish court-decisions dataset appeared without fanfare; expect more jurisdiction-specific legal corpora as RAG-for-law matures.
