## Main list

### 1. HarnessEval-W — agentified evaluation for world models · 4/5  
[paper](https://arxiv.org/abs/2608.16859) · [code](https://github.com/MirroS-Lab/HarnessEval-W) · [project](https://mirros-lab.github.io/HarnessEval-W)  
**Continuing story (6th run, traction +3.1× since 2026-08-18).** Replaces scalar benchmarks with an LLM judge that verifies physics, causality, and state consistency in video rollouts — the reasoning trace is the artifact. 248 GitHub stars, 123 HF upvotes. If you build or evaluate world models, this is the first benchmark that checks *why* a rollout fails, not just *that* it fails.

### 2. Embodied-Navigator (TAMP-Nav) — VLM navigation aligned to 2D priors · 4/5  
[paper](https://arxiv.org/abs/2608.17512) · [code](https://github.com/ZJU-OmniAI/Embodied-Omni) · [project](https://zju-omniai.github.io/Embodied-Navigator/)  
**Continuing story (5th run, traction +3.0× since 2026-08-19).** Forces VLMs out of unnatural action spaces by letting them point, reason in 2D, memorize landmarks, and align — 221 stars, 51 HF upvotes. The "point-think-memorize-align" loop is a clean abstraction for any embodied agent that needs to ground vision in action.

### 3. superwhisper/s1-mini — tiny ASR model on Qwen3 · 3/5  
[model](https://huggingface.co/superwhisper/s1-mini)  
Trending on HF (strong Tier-2 signal). A compact automatic-speech-recognition model built on Qwen3 with safetensors weights. No public benchmarks yet; the signal is author reputation + trending velocity. Worth a quick `generate()` test if you need lightweight ASR.

### 4. DavidAU/Qwen3.8-27B-Cold-Fusion-GAIN… — multimodal GGUF finetune · 3/5  
[model](https://huggingface.co/DavidAU/Qwen3.8-27B-Cold-Fusion-GAIN-V1.1-NM-DAU-NEO-MAX-MTP-GGUF)  
Trending on HF. Image-to-text GGUF built via "Cold-Fusion" + GAIN training on Qwen3.5-27B. Community finetune with unsloth; no evals published. Try if you want a local multimodal 27B in GGUF and can validate quality yourself.

## Insights

- **Evaluation is eating benchmarks.** The two highest-signal items both replace static metrics with reasoning traces (HarnessEval-W) or structured cognitive loops (TAMP-Nav). The pattern: *judge the process, not just the output*.
- **Qwen3 is the new community base.** All three new model releases are Qwen3/3.5 finetunes — GGUF, Cold-Fusion, GAIN, MTP. The ecosystem has converged on a single architecture for local experimentation.
- **Embodiment data is going public.** HiPHI (motion capture) + Embodied-Navigator (navigation benchmarks) suggest the sim-to-real data bottleneck is cracking for robotics.
