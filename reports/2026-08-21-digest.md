## Main list

### Continuing stories (carryovers with strong traction growth)

**[HarnessEval-W: Agentifying the Evaluation of Visual Worlds](https://arxiv.org/abs/2608.16859) · [code](https://github.com/MirroS-Lab/HarnessEval-W) · [project](https://mirros-lab.github.io/HarnessEval-W) — 4/5**  
4th run since 08-18; stars 238 → ~735, HF upvotes 121. A benchmark that replaces scalar scores with automated reasoning traces for world-model rollouts — checking physics, causality, and state consistency the way a human would. The artifact (repo + eval server) is live and the traction curve is steep. Continuing story, not a new arrival.

**[Embodied-Navigator: Point, Think, Memorize, and Align for Efficient Navigation](https://arxiv.org/abs/2608.17512) · [code](https://github.com/ZJU-OmniAI/Embodied-Omni) · [project](https://zju-omniai.github.io/Embodied-Navigator/) — 4/5**  
3rd run since 08-19; stars 218 → ~640. TAMP-Nav framework aligns VLM reasoning with 2D pre-training priors for embodied navigation, adding structured memory and adaptive reasoning schedules. Strong group (ZJU OmniAI), live code, and 3× star growth in days.

### Attention & long-context efficiency

**[Learning how to Forget: Fine-tuning for Long-Context Sparse Attention](http://arxiv.org/abs/2608.19920v1) — 3/5**  
Fine-tunes any KV-cache policy (H2O, SnapKV, etc.) on a single A100-40GB so the model co-adapts to the sparsity pattern — often beating exact-attention baselines. Efficient H2O implementation released. Directly addresses the KV-cache bottleneck for long-context serving.

**[Prompt-Conditioned Channel Attention for Hierarchical Feature Modulation toward Anatomy-Agnostic Segmentation](http://arxiv.org/abs/2608.20229v1) — 3/5**  
Introduces prompt-driven channel-wise modulation across hierarchical features for medical segmentation, replacing late-stage prompt fusion. Targets low-contrast, ambiguous boundaries across anatomies and modalities. Code released.

**[Contrastive Mixed Prompt Learning for Incomplete Multimodal Sentiment Analysis with Unseen Modality Combination](http://arxiv.org/abs/2608.20019v1) — 3/5**  
Tackles the realistic test-time scenario where modality combinations appear that never occurred in training. Contrastive prompt learning aligns shared and modality-specific representations. Benchmark + code released.

### RAG & retrieval compression

**[From Retrieved Context to Runtime Control: Adaptive Compression for Edge-based RAG](http://arxiv.org/abs/2608.19535v1) — 3/5**  
Moves context compression from a fixed offline budget to a runtime controller that adapts to workload and live KV-cache state. Reduces prefill, memory traffic, and energy on edge devices. Artifact available.

### Generative modeling & self-supervision

**[Flow Matching Meets 3D Curvilinear Structure Segmentation in Medical Imaging](http://arxiv.org/abs/2608.19965v1) — 3/5**  
Applies flow matching (faster than diffusion) to 3D vessel/nerve segmentation — complex topology, severe class imbalance, weak contrast. Generalizes across anatomies; code released.

**[Far from the Crowd: Scalable Self-Supervised Learning via Geographic Isolation](http://arxiv.org/abs/2608.19766v1) — 3/5**  
Curriculum for remote-sensing SSL that ranks samples by geographic isolation (from metadata alone, O(D log D), no image decoding). Works for contrastive and reconstruction objectives. No labels, no model feedback needed.
