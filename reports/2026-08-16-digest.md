## Main list

**[PlayWorld: Benchmarking World Models with Agent Players over Long-Horizon Objectives](https://arxiv.org/abs/2608.13552)** · [code](https://github.com/kxding/PlayWorld) · [project](https://kxding.github.io/project/PlayWorld/) — Continuing story, 2nd run, traction +225% since 2026-08-14. An interactive benchmark where agent players pursue long-horizon objectives inside video world models, replacing human eval with reproducible agent trajectories. 52 GitHub stars, 38 HF upvotes. · 4/5

**[cais/hle](https://huggingface.co/datasets/cais/hle)** — New today. The Humanity's Last Exam benchmark dataset, officially released under MIT with ~7.5K multimodal items. Already the reference target for frontier model evals; expect leaderboards to pivot here fast. · 4/5

**[Observal/Observal](https://github.com/Observal/Observal)** — New today. A local-first registry and analytics platform for AI components — skills, MCPs, agents — with a UI to define scope and share across teams. 2,361 stars in days; fills the "where do my agents live" gap for orgs running internal agent fleets. · 3/5

**[MaximeVandegar/Papers-in-100-Lines-of-Code](https://github.com/MaximeVandegar/Papers-in-100-Lines-of-Code)** — New today. 2,855 stars. Minimal, readable PyTorch implementations of key papers (transformers, diffusion, RL, etc.) — each under 100 lines. The fastest way to prototype from a paper without framework bloat. · 3/5

**[orcarouter/Qwen3.8-27B-Uncensored-FP8](https://huggingface.co/orcarouter/Qwen3.8-27B-Uncensored-FP8)** — New today. FP8-quantized, abliterated Qwen 3.5 27B (image-text-to-text). Drops refusal behavior while keeping multimodal capability; runs in ~16 GB VRAM. Useful for local agent loops that need vision + tool use without guardrail friction. · 3/5
