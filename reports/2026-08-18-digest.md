## Main list

### Agentic harnesses & world models

**[AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design](https://arxiv.org/abs/2608.13560) · [code](https://github.com/Yaxin9Luo/AutoDesign) · [project](https://autodesign.designanything.ai/) · 4/5**  
A framework that treats multimodal content creation as a long-horizon agentic process, letting the harness itself evolve through empirical exploration. 103 GitHub stars and 49 HF upvotes since Aug 14; traction still climbing (Δ+2.87×). Continuing story — 4th run tracked.

**[PlayWorld: Benchmarking World Models with Agent Players over Long-Horizon Objectives](https://arxiv.org/abs/2608.13552) · [code](https://github.com/kxding/PlayWorld) · [project](https://kxding.github.io/project/PlayWorld/) · 4/5**  
Interactive benchmark where agent players pursue long-horizon goals inside video world models, replacing human eval with reproducible agent trajectories. 65 stars / 43 HF upvotes since Aug 14; traction rising (Δ+2.48×). Continuing story — 4th run tracked.

### Benchmark & evaluation

**[Unsupervised Anomaly Detection for Image Dataset Quality Assurance in Multi-Center Breast MRI](https://arxiv.org/abs/2608.16725v1) · 3/5**  
Controlled AD benchmark of 17 realistic QA-relevant anomaly types (protocol violations, processing errors, anatomical anomalies) across six public DCE-MRI datasets. First automated dataset-QA mechanism for high-risk medical AI; code and benchmark released.

**[Graph Machine Learning: An Opportunity for Power Systems](https://arxiv.org/abs/2608.16494v1) · 3/5**  
Positions graph ML as the natural framework for grid-topology-aware operations (state estimation, contingency analysis, stability assessment). Releases a taxonomy of power-system tasks mapped to GML formulations plus open datasets — rare domain crossover with immediate operational relevance.

**[BERTopic-Virality Prioritisation: Scalable Thematic Analysis of COVID-19 and Monkeypox Misinformation](https://arxiv.org/abs/2608.15691v1) · 3/5**  
Couples BERTopic clustering with a post-hoc Virality Prioritisation layer and a two-stage hybrid misinformation detector. Outputs semantically coherent topics ranked by diffusion speed — actionable for public-health monitoring.

**[FirstDiff: One-Step Diffusion-Based Anomaly Detection for Multivariate Time Series](https://arxiv.org/abs/2608.15727v1) · 2/5**  
Predicts the initial noise instead of running full reverse diffusion, cutting inference to a single step while matching or beating multi-step baselines on MTAD benchmarks. Practical for real-time monitoring where compute budget is tight.

### Retrieval & long-context efficiency

**[Hypergraph-based Multimodal Retrieval-Augmented Generation with Incremental Refinement](https://arxiv.org/abs/2608.16628v1) · 3/5**  
Replaces bipartite graphs with hypergraphs to capture N-ary cross-modal relations (chart + caption + table), and refines incrementally rather than full-page reconstruction. Reduces token spend and noise in long-form M-RAG.

**[SEER: Long-Context Reasoning via Selective Visual-Text Compression](https://arxiv.org/abs/2608.15962v1) · 3/5**  
Renders text to images, then learns to visually scan and retrieve only query-relevant regions — dynamic compression instead of uniform downsampling. Cuts VL token usage while preserving extraction precision on long-context QA.

### Few-shot time-series

**[FETERS: Few-Shot Early Time-Series Classification via Effective Ratio Selection](https://arxiv.org/abs/2608.16385v1) · 3/5**  
Decouples "when to stop" from "what features to use" in early classification, selecting discriminative observation ratios per sample. Beats full-sequence baselines with 10–30% of the timeline observed under few-shot labels.

### Prompt data

**[fka/prompts.chat](https://huggingface.co/datasets/fka/prompts.chat) · 3/5**  
~1K–10K CC0-licensed chat prompts in CSV — clean, permissive seed data for instruction tuning or eval set construction. Trending on HF with strong download velocity.
