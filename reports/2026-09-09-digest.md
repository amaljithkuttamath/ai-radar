## Main list

### Benchmark
**gaia-benchmark/GAIA** · 4/5  
The GAIA dataset (466 questions across web, file, and API tasks) has become the de facto benchmark for agentic tool use. It’s small by design — n<1K — but its multi-modal, multi-step questions expose reasoning gaps that single-turn benchmarks miss. [Dataset](https://huggingface.co/datasets/gaia-benchmark/GAIA) · **Focus: benchmark**

**Chimaera: A Mixture-of-Graph-Experts Architecture** · 3/5  
Unifies graph prompt tuning, linear GNNs, and LLM-generated embeddings under a MoE router that selects experts per task and dataset. Early results show cross-dataset transfer without retraining — a practical step toward graph foundation models. [Paper](http://arxiv.org/abs/2609.08709v1) · **Focus: benchmark, embeddings, mixture-of-experts**

**AGOS-Bench: Air-Ground Cooperative Object Search** · 3/5  
First benchmark for UAV-UGV teamwork in urban search: aerial discovery + ground verification of target vehicles. Includes a trajectory dataset and a VLM-based agentic baseline. If you work on embodied multi-agent systems, this is the evaluation harness you’ve been missing. [Paper](http://arxiv.org/abs/2609.08402v1) · **Focus: agentic, benchmark**

**How AI Models Manage Epistemic Authority** · 3/5  
A conversation-analysis taxonomy of how LLMs respond when users challenge them — six challenge types, four authority-location layers. Reveals that models often concede authority too readily or dig in without evidence. Useful for anyone building evals for high-stakes advisory use cases. [Paper](http://arxiv.org/abs/2609.07662v1) · **Focus: evaluation, benchmark**

**TTGBench: Topological Evolution & Semantic Drift in Temporal Graphs** · 3/5  
Addresses a blind spot: existing temporal graph benchmarks over-index on link prediction and under-index on semantic drift. TTGBench adds realistic multi-class node classification over evolving text-attributed graphs and de-duplicates links to stop inflated scores. [Paper](http://arxiv.org/abs/2609.08226v1) · **Focus: evaluation, benchmark**

**Evolution of Multimodal QA: From MAE to UniMMQA** · 3/5  
A clean methodological comparison tracing three generations of multimodal QA — modality-adaptive extraction (MAE), Solar, and unified architectures (UniMMQA). Good map if you’re deciding which paradigm to build on. [Paper](http://arxiv.org/abs/2609.08896v1) · **Focus: benchmark**

### Video
**DreamLayer-Eval: Open-Source Benchmarking for Image & Video Diffusion** · 4/5  
Automates prompt sets, seed control, and metric computation (FID, CLIP, aesthetic, temporal consistency) across image and video diffusion models. 410★ and climbing. If you ship diffusion models, this replaces ad-hoc eval scripts. [Repo](https://github.com/TheDesignFounder/DreamLayer-Eval) · [Project](https://dreamlayer.io)

### Other
**microsoft/foldingdiff: Diffusion Models of Protein Structure** · 4/5  
Diffusion over torsion angles (trigonometry + attention) generates valid protein backbones without 3D coordinate regression. 566★, Microsoft Research backbone. Weights and training code open. [Repo](https://github.com/microsoft/foldingdiff) · **Focus: attention**

**EMBLEM: Multi-Script Table Detection via Masking** · 3/5  
Introduces MANDALA — 2,323 pages across 18 languages / 15 scripts — and a masking-based detector that closes the multi-script gap. Practical for document AI pipelines handling global paperwork. [Paper](http://arxiv.org/abs/2609.08330v1) · **Focus: retrieval**

**openai/clip-vit-base-patch32** · 3/5  
The original CLIP ViT-B/32 re-surfacing on HF trending — likely downstream adoption in new pipelines (retrieval, filtering, reward models). Weights for PyTorch/TF/JAX. [Model](https://huggingface.co/openai/clip-vit-base-patch32)
