## Main list

### Agents

**[VETTA: Coordinating Turn- and Token-Level Credit Assignment for Multi-Turn LLM Agents](http://arxiv.org/abs/2610.08402v1) · 3/5**  
Introduces a two-level credit assignment framework that learns which responses and which token-level decisions drive outcomes in multi-turn agent trajectories. Addresses the gap where turn-level methods ignore within-response decisions and token-level methods don't model per-response credit. Code and experiments available.  
[paper](http://arxiv.org/abs/2610.08402v1) · [code](https://github.com/vetta-agents/vetta)

**[WorldSolver: Can LLM Agents Simulate Physical Dynamics via Solver Generation?](http://arxiv.org/abs/2610.08720v1) · 3/5**  
Tests whether LLM agents can write executable physics solvers from natural language problem descriptions — identifying models, formulating dynamics, and implementing numerical integration. Benchmarks across rigid-body, fluid, and deformable scenarios; finds current agents succeed on simplified cases but struggle with multi-physics coupling.  
[paper](http://arxiv.org/abs/2610.08720v1) · [code](https://github.com/worldsolver/worldsolver)

**[Learning to Retrieve via Reinforcement Learning in Embedding Space](http://arxiv.org/abs/2610.07731v1) · 3/5**  
RELER fine-tunes dense retrievers with RL directly in embedding space using von Mises-Fisher sampling, optimizing for task-specific retrieval metrics rather than contrastive proxies. Improves nDCG and downstream QA on BEIR and MS MARCO without changing index structure.  
[paper](http://arxiv.org/abs/2610.07731v1) · [code](https://github.com/reler-retrieval/reler)

**[Sensor-Language-Action Models](http://arxiv.org/abs/2610.08244v1) · 3/5**  
Unifies multimodal sensor observations, language, and heterogeneous actions in a single transformer. Language serves as the semantic interface between sensing and acting, enabling zero-shot action prediction and explanation across robotics and embodied tasks.  
[paper](http://arxiv.org/abs/2610.08244v1) · [code](https://github.com/sla-models/sla)

### Video

**[knightyxp/VideoCoF — Unified Video Editing with Temporal Reasoner](https://github.com/knightyxp/VideoCoF) · 3/5**  
CVPR 2026 Highlight. A unified framework for video editing tasks (object insertion, style transfer, motion editing) driven by a temporal reasoning module that maintains consistency across frames. 210 GitHub stars; inference code and checkpoints released.  
[repo](https://github.com/knightyxp/VideoCoF) · [project](https://videocof.github.io)

### Google Embedding Gemma-2

**[google/embeddinggemma-2](https://huggingface.co/google/embeddinggemma-2) · 3/5**  
New sentence-transformer compatible embedding model from Google, built on Gemma-2 architecture. Safetensors format, optimized for feature extraction and semantic search. Trending on Hugging Face with strong early adoption signals.  
[model](https://huggingface.co/google/embeddinggemma-2)

### Benchmark

**[Multi-Label Perceptual Bug Detection in Video Games](http://arxiv.org/abs/2610.08593v1) · 3/5**  
ResNet-BiLSTM model detects multiple simultaneous perceptual bugs (texture corruption, lighting artifacts, clipping) from gameplay footage. Outperforms I3D and 3D ResNet baselines on a new multi-label benchmark; dataset and code released.  
[paper](http://arxiv.org/abs/2610.08593v1) · [code](https://github.com/game-bug-detection/multilabel)

**[Improving Synthetic Data Generation for Argument Mining via Adversarial RL](http://arxiv.org/abs/2610.07699v1) · 3/5**  
Adversarial RL framework generates structurally accurate, diverse argument mining annotations — addressing the scarcity of high-quality AM datasets. Generator-discriminator loop improves both logical structure and linguistic variety; downstream AM models match human-annotated baselines.  
[paper](http://arxiv.org/abs/2610.07699v1) · [code](https://github.com/argmining-advrl/synthetic-am)

### Other

**[YuvrajSingh-mist/Paper-Replications](https://github.com/YuvrajSingh-mist/Paper-Replications) · 4/5**  
From-scratch PyTorch replications of transformers, attention variants, GANs, diffusion, CLIP, LoRA, MoE — each with reproducible training loops. 428 stars in days; clean, pedagogical code aimed at researchers and engineers building from fundamentals.  
[repo](https://github.com/YuvrajSingh-mist/Paper-Replications)

**[Asymptotic Analysis of ERM on Heavy-Tailed Data](http://arxiv.org/abs/2610.07637v1) · 2/5**  
Precise asymptotic characterization of prediction risk for linear regression with entry-wise α-stable features. Introduces a functional order parameter capturing how rare large entries persist in high dimensions — relevant for robustness in real-world heavy-tailed regimes.  
[paper](http://arxiv.org/abs/2610.07637v1)

## Insights

- **Agent memory is splitting into two tracks**: explicit belief-state maintenance (PoS, OneStreamer) and credit-assignment for learning (VETTA, WorldSolver). The former targets inference-time coherence; the latter targets training-time signal propagation.
- **Video editing is converging on temporal reasoning modules** — VideoCoF's "temporal reasoner" and OneStreamer's "proactive generation" both address frame consistency through learned reasoning over time, not just better attention.
- **Synthetic data generation is moving from prompt-engineering to adversarial RL loops** — the Argument Mining paper and DAEDALUS both use generator-discriminator dynamics with RL to enforce structure and diversity.
- **Embedding models are fragmenting by use case**: embeddinggemma-2 targets general semantic search; RELER targets task-specific retrieval via RL fine-tuning. Expect more specialization.
