# AI Radar v0.2 overhaul — 2026-10-24

## Scope and decisions

This overhaul replaces duplicated shell orchestration with a validated Python
runtime while keeping the existing collector modules, public report paths,
ID-keyed movers state, and external board/grader boundaries.

The implementation prioritizes trustworthy observations and publication over a
framework rewrite or moving the public website into this repository. Source
blocking and bounded prompt experiments remain useful and were integrated.

## Changes to everyday operation

- Use `uv run python -m radar demo` to try the pipeline without credentials.
- Use `collect`, then `distill --backend template` to inspect real collected data.
- Use a real backend to publish. `dryrun` and `template` now **always** write previews.
- Run `doctor` for a local freshness/health report; `doctor --json` is machine-readable.
- Local CLI runs never send email. Delivery is a separate command or an explicit
  manual workflow input, after real publication.
- `FOCUS=""` disables profile matching. Embedding-based focus/clustering are explicit
  opt-ins. Preview runs force lexical behavior even with embedding environment flags.
- `routines.yaml` defaults now take effect. CLI overrides environment, which overrides
  routines for common settings. The CLI rejects invalid settings and lookback >31d.

## Data migration

No historical reports or evaluation results are rewritten by the overhaul itself.
No synthetic example becomes a public digest. Existing `seen.json` lists remain
readable but no longer suppress returning IDs. Raw files are regenerable; both old
and new hashed filenames can be read, and duplicate observations collapse by ID
and latest fetch timestamp. Invalid legacy records are logged and skipped.

On the next real publication, `state.json` gains `last_seen` per item. Legacy
snapshots have no daily boundary, so the first new snapshot starts a daily streak
rather than pretending to know consecutive-day history. Same-day reruns no longer
inflate that streak. Scores now use all five observed criteria; the model cannot
add a subjective novelty point.

`data/publication.json` is an additive public receipt. `data/collection.json` is
artifact-local. Keep source health and raw observations together when moving a
corpus between machines. New CI expects the new artifact layout; run collection
once after landing these changes before manually distilling an older artifact.

## Behavioral protections

- Fresh checkouts retain repeat observations even when the ID is already in Git.
- HTTP timeouts, bounded retries, response size limits, and source-level diagnostics.
- Shape validation, safe primary URLs, finite signal values, and timezone-aware dates.
- Domain blocking applies to cached observations as well as newly written ones.
- Safe previews, candidate bounds, source diversity, and unused quota backfill.
- Model output checks for requested date, usable content, and input-grounded links.
- Atomic file replacement and restoration of prior reports/state on handled failures.
- Collection manifests distinguish quiet sources, degraded coverage, and total failure.
- Tests isolate their filesystem and replace external network/model boundaries.

## What still requires operational verification

The local test suite uses controlled provider responses. Real synthesis credentials,
provider quotas/model availability, SMTP delivery, and GitHub-hosted workflow
execution must be verified in their deployed environment. Structural output checks
cannot prove prose correctness; the independent grader remains necessary.

Local health checks read the checked-out artifacts, not the live website or remote
workflow state. Historical July snapshots in this checkout do not by themselves
establish whether the remote deployment is currently running.

  failure on a conflicting rebase. No remote GitHub repository was modified.

  overhaul. The local demo remains under ignored runtime storage.

## Integration with current main

Rebased onto the production history before publication. Preserved `llm.py`, the
independent `grader/` package, tracking, health, and regression monitoring. The
shared provider replaces the retired GitHub Models call path in synthesis and
replays. Explicit previews remain isolated; automatic degraded publication keeps
the existing production continuity contract. All 609 combined tests pass on Python 3.10 and 3.13; lint, formatting, and the isolated offline demo also pass.
